# 法文第46–50回回顾

2026-11-14。五回397区块已全文翻译、逐段中法对读并独立复审。正文直接编辑HTML，无正文JSON副本或重建步骤；只本地commit，不push。

- 第46回：43块。邢夫人求妾、鸳鸯拒绝、姑嫂争执、贾赦威胁、贾母错怪及探春解围完整，无新增占位。修许诺地位并肩、朋友反讽、拒绝而非好感偏好；父亲病情和母亲耳聋不混同，贾琏与宝玉的猜疑不擅作互斥。誓言和婚姻拒绝按人物原话保留。
- 第47回：37块。牌局、赖家宴席、柳湘莲与宝玉谈旧友、薛蟠误认及挨打、宝钗劝母完整。半个时辰按约一小时，修三五年和三四十次的范围表达。贾母指斥商量加害妻子保持在引语中；宝钗对母亲称薛蟠为mon frère，不误为notre frère。
- 第48回：53块。薛蟠出行、石呆子扇案、香菱学诗及两首试作完整。金泛指钱财，不实写金币；古诗虚实用保守术语及短注，不缩成现代连词规则。修天明时间语序和梅花香染月色的方向。保留人物评诗的层次，不把香菱未成熟的试作润成无瑕成品。
- 第49回：54块。香菱新诗、亲属来访、各人安置、宝黛谈心、雪衣和鹿肉宴完整。修半轮月为将沉月轮的形象，不写成一夜月相改变；嫦娥是发问者，不倒置。三个虚字明确是原文三汉字；栊翠庵统一为ermitage de la Verdure enclose。野鸡瓜齑保留腌瓜菜义，不强定单一品种。
- 第50回：210块。雪景联句的说话者、全部诗行、红梅诗、访妙玉、宝琴已许梅家之事与灯谜完整。未将人物揣测擅成定论。修含鸳鸯琥珀在内的五六人数，紫羯褂明确羊皮，地名统一。“淋竹醉堪调”采用雪压竹如醉、调弄戏玩的释读，不擅添调酒或确定音乐典故。

## 释读参照

“淋竹”句有不同解释，本批采用雪压竹倾斜如醉、调为调弄戏玩的注释；不是遗漏“醉”或“调”。[诗词注释第36条](https://www.kekeshici.com/gushiwenshangxi/hongloumeng/100860.html)。仅核词义，法译独立完成。
