# 韩语前八十回翻译标准

以 classics/hongloumeng/ch001.html 至 ch080.html 当前作者校正中文正文为唯一翻译底本，不从外语转译；遵守已有作者裁定，不擅改中文。正文直接保存在 classics/hongloumeng/ko/chNNN.html，保留 data-source-block、data-kind 与中文段落类别和布局类，便于直接编辑及逐段对读。

译名、叙述语气及称呼以 originals/hongloumeng/ko/ch081.html 至 ch085.html 当前HTML为准，不以received旧稿覆盖现稿。已核实王熙凤用희봉（凤姐在叙述中同用），宝钗用보차，而非先前草拟的보채；其余主要译名为보옥、대옥、습인、평아、청문、가모、왕부인、가련。汉字音为主，人物当面称呼按辈分与身份自然处理。书名홍루몽，作者조설근。诗联保留意象、语义和行次，不强押韵，不添加判词人物归属和结局。保留钱币、年龄、时间、衣物与礼俗细节。

每五回完成中韩全文对照、自审和跨回称名检查，记录真实审核范围与残留事项，再本地git commit；不push。自动结构检查不等同文学审校，不发布未完成回目的入口。

经用户授权，在确实无法直接处理的具体性细节处参照已获认可的德语/西语非露骨表达尺度，保留叙事、人物关系、拒绝和强迫，勿写成自愿、勿扩写性细节，不更改人物年龄。普通成人和非露骨叙事如实翻译，不设置无必要占位。任何淡化必须在本批复核记录中注明章节与区块，含蓄改写不得宣称逐字无删减。

节名统一：中秋用 중추절；元宵可按语境写 정월 대보름／원소절，指中国故事中的节日，不添加韩国地方习俗。
