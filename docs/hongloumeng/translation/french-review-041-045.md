# 法文第41–45回回顾

- 第41回：32块。木杯、茄鲞、栊翠庵品茶、镜门与醉卧情节完整。修饮酒分配语法、食量与煮茶浓度表述，统一宝玉与妙玉的称谓语域。茶器题字保留原字，短注说明；“鸡瓜”疑词保守处理为炒鸡肉块，不擅改中文或断言鸡爪。
- 第42回：39块。巧哥儿取名、赠物、问诊、宝黛规劝与画园讨论完整。修“内造”为御造来源，而非仿宫廷做法；诊脉左右手明确属于医师。绘画材料清单逐项核数量，保留无法稳妥细定的专名；金箔二百帖按册而非单张，担笔按画笔而非笔架。
- 第43回：37块。凑份、尤氏退份、宝玉私祭及回席完整；所祭何人不提前揭明，洛神议论留在人物引语。修总人数、含宝玉的代词、施礼动作和标题“撮土为香”，不误作以土为香炉。
- 第44回：36块。捉奸、平儿受责、宝玉理妆、赔礼、鲍二妻之死与丧资账目完整。凤姐转述的毒杀指控限定在她的引语，不改成客观事实。修辱骂对象、凤姐向平儿道歉的方向、鲍二妻与凤姐的指代，以及母家亲属不误成双亲。修法语倒装句。无新增删节或占位。
- 第45回：51块，含《秋窗风雨夕》20行。诗社监社、赖家宴请、宝钗劝病、宝黛雨夜探访及燕窝送达完整。修首次诗社出席不全、出钱后是否赶人的反问、老封君非宫廷女侍的称谓、杂书及馈赠用语。诗中“连宵”保留连续多夜，秋字反复与诗行完整；人物医理保持在人物语境中。

## 核词依据

- “鸡瓜”与“鸡瓜子”有异文及不同释读；程乙本仍用“鸡瓜子”，不足以擅定为鸡爪。[原文对照](https://zh.wikisource.org/zh-hans/紅樓夢（程乙本）/第四十一回_至第五十回)。
- 绘画材料清单中担笔列为画笔，金箔“帖”为包装单位，不擅换算张数。[书画材料资料](https://www.zgshscjxh.com/nd.jsp?id=1517)、[广东省博物馆研究资料](https://www.gdmuseum.com/upload/cn/file/2025-01/1736297595579.pdf)。
