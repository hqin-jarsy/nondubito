# 第5回《喜冤家》现行读法补充

作者明确指定本版将“一味的骄奢淫荡贪还构。”改作“一味的骄奢淫荡贪欢媾。”。这是本版可读性选择，不认定旧刻为乱码，不宣称复原唯一古本。历史CRIT-008及READABLE-CRIT-008保留为旧阶段证据；它们的“贪婪而又构陷”释义不再支配本句现行翻译。

英文现行句：Nothing but arrogance, extravagance and debauchery, craving carnal pleasure.

日文现行句：ひたすら驕り、贅沢し、淫らにふけり、男女の歓びを貪る。

本次仅重新审读这个改变的曲句及其上下文，并核对其他已验收内容不变。不将旧的全回审读重新标作本日完成，也不推广到癸酉本其他异文。
