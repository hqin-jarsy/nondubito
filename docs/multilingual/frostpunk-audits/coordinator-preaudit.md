## Mechanics requiring correction/verification before translation

1. Sources: https://frostpunk.fandom.com/wiki/People and law UI transcriptions. First child labor tier is safe jobs; mine/factory wording needs dangerous-jobs tier, not automatic from first law.
2. EP1 zero hope/max discontent = immediate expulsion should distinguish ultimatum/time to restore conditions. New Order still allows discontent overthrow, so EP3/4 cannot equate locked hope with literally impossible dissent.
3. EP1 one-law-free survival inevitably dies / no moral and effective route are absolute gameplay claims; preserve pressure felt by inexperienced player, not universal impossibility.
4. EP1 every action citywide and no individual intervention: buildings' shifts/heaters/staffing and named-citizen events contradict literal universality. Retain aggregate-management lens with scope limits.
5. EP2 prisoner-wall-graffiti event exact options and cost not verified. Need original event transcription before retaining zero-cost disregard/exact no-music statement.

7. EP2 introduces Order before EP3 unlocks Purpose; can make EP2 retrospective/example ordering rather than false chronological progression.
8. EP3 Order vs Faith similar political endpoint does not make all gameplay functions identical; keep interpretive comparison without claiming exact mechanics parity.
9. EP3 final law signing is not merely unceremonious icon swap; event/cutscene/violence claims need actual original sequence. Avoid exact no-celebration/no-scene negatives absent audiovisual verification.
