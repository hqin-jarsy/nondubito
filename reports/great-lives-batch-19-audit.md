## 逐篇审读

### 055 爱迪生

九节顺序：专利背后的房间 → 灯泡与供电服务 → 声音和电影的生意 → 技术更替中的人 → 电流之争 → 实验与判断 → 特斯拉和爱迪生 → 名字离开招牌 → 不能熄灭的灯。

- 1093项是美国专利数，不是无人能够接近的永久纪录。门洛帕克是工业研究的重要先驱，不是所有实验室唯一的起点；巴彻勒等合作者具有自己的判断，不是天才的工具。
- 1879年10月关键试验使用碳化棉线，竹丝在后。斯旺等人的工作得到保留，灯泡与发电、配电、维修的系统分开说明。珍珠街供电写1882年，不争夺含混的“世界第一”。
- 留声机的录音与重放不等于发明此前所有声音记录。电影部分保留迪克森与团队，窥孔观看的活动电影视镜与影院放映区分。
- 新照明没有在某一天消灭旧照明。技术带来的机会、工作变化、费用与风险不能被“进步”一词包办。
- 交流电的早期变压优势不等于直流电永远落后；现代高压直流边界保留。电刑部分区分布朗与爱迪生方面的角色，不用Topsy事件拼出单一反派。
- 不把“汗水”理解为无需思考的穷举，也不以一万次失败等名言传说作试验计数。铁矿石选矿的失败保留，使坚持成为需要判断的问题。
- 特斯拉与爱迪生不是各欠一半的人。1917年奖章由美国电气工程师学会颁发，不是两人的私人和解典礼。
- 1892年通用电气合并改变名称与控制，不等于爱迪生此后被彻底逐出电力研究；同年的研究、专利关系仍在。失去主导的私人感受不由寓言代写。
- 1931年10月20日胡佛声明建议21日个人自愿熄灯一分钟，并明确反对停发电厂。结尾从“全国一齐黑暗”的传说改为仍需要亮着的灯。接线与桥头群像明确属于文学想象。

主要核对：[国家公园管理局生平](https://www.nps.gov/edis/learn/historyculture/edison-biography.htm)、[碳丝灯史料](https://edison.rutgers.edu/life-of-edison/biographical-essays/lighting/the-carbon-filament-lamp)、[1892年年表](https://edison.rutgers.edu/edit-chronology/chronology-details/1891---1900/1892)、[电流之争](https://edison.rutgers.edu/life-of-edison/essaying-edison/essay/the-current-wars)、[胡佛原声明](https://www.presidency.ucsb.edu/documents/statement-national-tribute-thomas-alva-edison)。文末另列研究所、电影、奖章和输电技术资料。本轮不声称通读旧注释所列整部传记。Rutgers电流史页面的Kemmler年份与其他档案不一致，不沿用其1889年；能源部FAQ只用于交流变压与现代高压直流说明，不沿用其珍珠街年份。

### 056 海森堡

九节顺序：被占领城市中的会面 → 矩阵与显微镜 → 测量不是魔法 → 爱因斯坦的追问 → 留在德国 → Farm Hall的广播 → 对面的人 → 蒯因不能提供免责 → 放低手里的纸。

- 1941年会面的时间背景可核对，谈话地点、内容和目的则存在互相冲突的后述。不把散步写成已有双方认可记录的场景，更不把“阻止造弹”当成已证实的秘密任务。
- 矩阵力学保留玻恩、约尔丹的工作。1927年显微镜思想实验与严格的不等式分开；凯纳德1927年证明和罗伯逊1929年推广不被抹去。
- 位置与动量的不确定性用同态制备的两组系统、统计分布解释，不归因于仪器粗糙，也不等于意识创造世界。测量扰动与制备状态的统计分散分开。
- 1932年度诺贝尔奖在1933年颁发。“哥本哈根诠释”不写成三人完全一致的宣言；爱因斯坦的关切包括完备性和远隔系统，而非单纯不喜欢随机。
- 贝尔检验限制特定假设下的局域隐变量解释，不排除一切隐变量理论，也不选出唯一诠释。
- 留在德国的理由可以被理解，但不能从资源、机构、军方利益中剥离实际工作。未造出炸弹不自动证明道德抵抗成功，研究参与也不授权叙述者编造一切最坏动机。
- Farm Hall秘密录音保留8月6日最初反应、14日技术说明及彼此对自我辩解的争执。不把一次录音当作透视内心的全知材料；也不因其局限而舍弃证据。广岛受害者不是科学家心路的布景。
- 1961年生日祝电及回复表明战后联系仍在，不写成三十五年绝交。玻尔有权质疑和拒绝；是否原谅不由本文替他决定。
- 人的动机难以完全查明，不是量子不等式的推论，更不等于已经知道的行为无需负责。桥头保留科学贡献与历史责任，两者不能相互抵销。

主要核对：[玻尔档案馆发布说明](https://nbarchive.ku.dk/collections/bohr-heisenberg/introduction/)、[文件目录与1961年回复](https://nbarchive.ku.dk/collections/bohr-heisenberg/documents/)、[Farm Hall原始记录节选](https://germanhistorydocs.org/en/nazi-germany-1933-1945/ghdi:document-2320)、[AIP历史展](https://history.aip.org/exhibits/heisenberg/farm-hall.html)、[诺贝尔奖记录](https://www.nobelprize.org/prizes/physics/1932/summary/)、[测量不确定性研究](https://arxiv.org/abs/1312.4392)。档案馆公开草稿多写于1957–1962年，不是1941年同步记录；本轮阅读Farm Hall公开节选，不声称通读全部录音档案。研究论文摘要用于区分两类不确定性，不声称据此完成其数学证明审查。

### 057 玻尔

九节顺序：太极纹章 → 原子与桌上的书 → 装置的问题 → 爱因斯坦 → 占领中的会面 → 过海 → 开放世界 → 与西田并坐 → 未寄出的信。

- 1947年大象勋章与纹章保留，但互补性不解释为相同条件下相互矛盾的断言同时成立，更不把不同历史叙述宣布为同样有据。
- 1912年与卢瑟福工作、1913年原子模型和1922年诺贝尔奖分开。定态不是电子静止，轨道模型不是现代量子态的照片；模型解释氢谱的贡献与多电子原子局限并存。
- 1927年科莫与实验条件保留。局部检测和干涉图样可以并存；完整路径信息与未减弱干涉的冲突，不写成任何波粒特征都绝不能同时出现。
- EPR关切与玻尔1935年回应分开交代。玻尔在原文特意排除该关键阶段的机械扰动说；纠缠不提供可任意控制的超光速消息。贝尔结果不替玻尔所有哲学判断背书。
- 1941年的记忆冲突和战后联系保留。未寄信不能被解释成永不原谅、完全原谅或不愿使“叠加态塌缩”。
- 1943年丹麦犹太人营救是共同工作，不写成玻尔一人说服国王救出所有人。难民身份不免除其后来参与战时核项目的责任。
- 1950年联合国公开信包含合作、信息交流、监督和共同安全，不简化成互相信任即可。战时已经提出的开放主张，也不是核爆之后才突然产生的悔悟。
- 西田、蒯因与玻尔的问题可以对读，不写成同一发现的三种语言；人的资格不需要由量子物理证明。中英及繁体清理译腔句式，日文会面用“谈话”而非确定的散步，韩文定态用“정상 상태”避免静止误解。
- 1962年去世与后来的草稿公开有据；临终仍在黑板推导之类场景不作确证叙述。桥上的信属于文学想象，不预设和解。

主要核对：[玻尔1935年回应原文](https://journals.aps.org/pr/pdf/10.1103/PhysRev.48.696)、[玻尔档案馆](https://nbarchive.ku.dk/collections/bohr-heisenberg/)、[丹麦营救资料](https://encyclopedia.ushmm.org/content/en/map/rescue-of-danish-jews-fall-1943)、[1950年联合国公开信](https://www.atomicarchive.com/resources/documents/deterrence/bohr-un-letter.html)、[玻尔研究所核研究史](https://nbi.ku.dk/hhh/bohr/bohr/kernefysik/)。本轮核对了公开信及原始回应的相关段落，不声称通读旧稿列举的整部人物传记。
