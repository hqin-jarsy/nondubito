## 逐篇内容与校订

### 049 康托尔

九节顺序：配对的问题 → 椅子、偶数与有理数 → 对角线构造 → 幂集与层级 → 连续统假设 → 德德金的贡献与署名 → 三位数学家的不同边界 → 超穷与绝对无穷 → 可以休息的桥头。

- 分开1874年的不可数证明与1891年的对角线论证，也分开有理数格子的斜线枚举与不可数证明。
- 小数构造只用1、2，避免重复小数表示造成的漏洞。
- 幂集操作不直接等同于走到下一阿列夫；连续统假设的独立性保留ZFC一致性条件及框架范围。
- 哥德尔1938年结果、1940年专著与科恩1963年结果分开。比较哥德尔、图灵不再写成三人证明同一个哲学原则。
- 保留克罗内克争论的实质，不把全部学界写成统一拒绝，也不用一个难题或一个反对者解释精神疾病。
- 补回德德金通信及未获充分署名的问题。2026年的新近报道明确作为报道处理，不冒充本轮亲自查验原件，也不把功劳争议写成全部成果均为剽窃。
- 希尔伯特的天堂之喻放回康托尔身后。结尾不再用“疯眼睛”装饰天才；桥头可以讲解，也可以休息。

核对资料：[连续统假设](https://plato.stanford.edu/entries/continuum-hypothesis/)、[圣安德鲁斯大学数学史](https://mathshistory.st-andrews.ac.uk/Biographies/Cantor/)、[哈勒大学康托尔协会历史资料](https://www.cantor-vereinigung.uni-halle.de/historie/)、[Quanta关于德德金书信的2026年报道](https://www.quantamagazine.org/the-man-who-stole-infinity-20260225/)。

### 050 哥白尼

九节顺序：临终收到书 → 行政、医药与观测 → 把观察者放进图中 → 抽屉中的年月 → 后世审判 → 匿名序言 → 读者修正前人 → 与达尔文对读 → 书被下一位读者接起。

- 区分临终收到成书的记述与出版日期；手指、墨香、微笑不作已核实史实。
- 教会职务、教会法学历、行政及医药工作不再被压成“闲时看星星的神父”。
- 托勒密模型不写成愚蠢补丁；哥白尼仍有圆周运动与本轮，也不立即拥有全部现代证据。
- 不把早期手稿到出版之间的时段写成从确定发现日算起的精确三十六年；保留教会内部的鼓励及雷蒂库斯的推动。
- 1616年暂停、1620年修正、伽利略审判、布鲁诺多项指控及1992年讲话分别处理。死亡不被写成把危险故意留给后人。
- 重点校正：《致读者》由奥西安德匿名插入，不是哥白尼本人对教皇说自己不相信地球运动；承印者佩特雷乌斯又是另一人。
- 金星相位可由第谷式模型解释，不能单独写成完整排除静止地球的一锤定音。开普勒并非仅替前人添证据，而是修改其珍视的圆。
- 中世纪宇宙中心不总是荣耀位置；失去中心不等于失去价值，是本文的伦理思考而非天文学定理。
- 2005年发现遗骸、2009年遗传研究、2010年重新安葬分开；不把鉴定写成绝对无误，也不混同首次纪念。

核对资料：[哥白尼献词原典英译](https://faculty.tnstate.edu/tcorse/h120/Copernicus.htm)、[斯坦福生平及天文学研究](https://plato.stanford.edu/entries/copernicus/)、[密歇根大学奥西安德馆藏说明](https://www.early-astronomy-um.org/western_osiander.php)、[1620年修正令](https://www.vaticanobservatory.org/sacred-space-astronomy/139476-2/)、[1992年讲话原文](https://www.pas.va/en/magisterium/saint-john-paul-ii/1992-31-october.html)、[2009年遗传研究](https://evo.dbio.uevora.pt/Genetic_identification_of_putative_remains_of_the_famous_astronomer_Nicolaus_Copernicus.pdf)、[金格里奇对墓葬研究的说明](https://pmc.ncbi.nlm.nih.gov/articles/PMC2718392/)。

### 051 萨特

九节顺序：门打开而人留下 → 树根与偶然性 → 裁纸刀和人的不同 → 处境中的自由 → 自欺的两种方向 → 与克尔凯郭尔、黑格尔的对话 → 公交队伍与历史 → 波伏瓦及其他人的位置 → 不再索要终身判决。

- 《禁闭》的门确实打开，不能把整个困局写成物理上始终无法离开。使用萨特自己的后续说明，避免把所有关系都写成地狱。
- 《恶心》的文学体验不取消生物学功能，也不直接推出人的生命无价值。
- “存在先于本质”不写成婴儿没有任何继承条件，或凭意志就能获得所有能力。
- 自由与全能分开；承认行动余地不等于让人替别人施加的压迫负责。保留青年选择的具体代价。
- 服务员是哲学例子，不是对实际劳动者的远程诊断。自欺同时可能表现为把角色当作全部，以及否认事实、承诺、身体条件。
- 不把萨特当作简单减去上帝的克尔凯郭尔；保留《方法问题》对个人痛苦与历史关系的双重要求。
- 《辩证理性批判》未完成不证明自由和社会分析原理上不相容；政治目的不自动替手段免责。
- 波伏瓦不是萨特生活方式的证明；两人关系之外的参与者也有同意、拒绝和被认真对待的资格。五十一年不自动证明一种关系模型优越。
- 结尾明确另写相遇，不伪称给原剧加上幸福结局；老年依赖也不被“独自作主”的形象抹去。

核对资料：[《禁闭》法文教学转录](https://mmegousset.files.wordpress.com/2018/01/huis-clos-texte-integral.pdf)（核对门打开后的场景，不把教学文件首行年份当首演日期）、[法国国家图书馆所录作者说明](https://expositions.bnf.fr/sartre/feuilletoirs/manuscrits/06.htm)、[1945年演讲英译](https://www.marxists.org/reference/archive/sartre/works/exist/sartre.htm)、[《方法问题》开篇英译](https://www.marxists.org/reference/archive/sartre/works/critic/sartre1.htm)、[萨特研究](https://plato.stanford.edu/entries/sartre/)、[波伏瓦研究](https://plato.stanford.edu/entries/beauvoir/)、[法国国家图书馆《辩证理性批判》说明](https://expositions.bnf.fr/sartre/expo/salle2/15.htm)。
