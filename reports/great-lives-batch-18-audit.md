## 逐篇审读

### 052 波伏瓦

九节顺序：默认的“人” → 后天形成的生活 → 自然化的命令 → 处境与钥匙 → 作者本人的责任 → 居里与普通人的机会 → 洞穴中的画像 → 历史安排的真实重量 → 墓地与转回来的镜子。

- “女人不是天生的”不写成身体不存在、婴儿是白纸，或一个人能够随意选择一切。家庭、爬树等场景明确是说明性例子，不冒充跨文化调查。
- “第二性”保留从属关系的含义，不弱化成第二个被看见的性别；传统内部的分歧也不被压成两千年统一阴谋。
- 修正精神分析部分的简化；解剖差异与社会评价分开。
- 1944年、1947年的哲学著作呈现她自己的问题意识，不写成萨特的脚注，也不靠宣称萨特完全忽略处境来突出她。
- 法国女性1944年取得选举权与1945年首次投票分开。1965年改革放在此前多次改革之后，不把此前所有已婚女性的法律情形说成一样。
- 纳入比安卡·朗布兰关于伤害的当事人证言，区分证言与全知裁决；教师、名人与年轻参与者之间的权力差距不能被“自由实验”遮住。
- 受过压迫不使作者自动无辜。专一、重新协商、拒绝与退出都可以属于自由，不替任何一种关系模式颁发优越证明。
- 居里的成就不是女性获得普通机会的资格考试；普通人的生活也不以卓越为前提。
- 《理想国》第五卷允许符合条件的女性成为护卫者，不等于已经实现现代性别平等。历史形成的安排仍有物质重量。
- 开头、洞穴和桥头是文学想象；墓地和身后回望不伪装成对人物内心的直接记录。

主要核对资料：[《第二性》导言](https://www.marxists.org/reference/subject/ethics/de-beauvoir/2nd-sex/introduction.htm)、[精神分析章节](https://www.marxists.org/reference/subject/ethics/de-beauvoir/2nd-sex/ch04.htm)、[《模糊性的道德》](https://www.marxists.org/reference/subject/ethics/de-beauvoir/ambiguity/ch02.htm)、[斯坦福哲学百科](https://plato.stanford.edu/entries/beauvoir/)、[朗布兰回忆录书目及作者介绍文字](https://www.bnfa.fr/livre?biblionumber=18618)、[法国国民议会投票权资料](https://www.assemblee-nationale.fr/dyn/histoire-et-patrimoine/deuxieme-guerre-mondiale/l-accession-des-femmes-au-droit-de-vote)、[INA关于1965年改革的说明](https://www.ina.fr/ina-eclaire-actu/13-juillet-1965-les-femmes-mariees-s-emancipent)、[《理想国》第五卷](https://www.platonicfoundation.org/translation/republic/republic-book-5/)。朗布兰材料本轮核对的是书目页所录当事人文字，不声称通读整部回忆录。

### 053 蒯因

十节顺序：两个教条 → 单身汉与猫 → 辞典与红杯子 → 信念之网 → 卡尔纳普的回答 → 休谟与双陆棋 → 人物系列的地图 → 海森堡及西田 → 旅行者和教师 → 桥头的粉笔。

- 分开分析／综合、先天／后天、必然／偶然，不把康德的先天综合判断从问题中抹掉，也不混同可说与不可说。
- 辞典对既有用法的记录不能单独给出不循环的同义性解释；不写成“辞典来自经验，所以辞典错了”。
- 红色与缺口杯子的作者自拟例子区分外延重合与意义相同。明确规定新符号的定义仍可以使用。
- 1951年的论证是有争议的哲学主张，不是已证明所有界线不存在。背景假设与局部修正有不同范围，不是每次看猫都在检验整个宇宙。
- 加入1991年回顾中的温和整体论，避免把可修正性写成任意否认证据。
- 卡尔纳普对框架规则的用途、格赖斯和斯特劳森对论证的反驳得到真实位置；难以给出不循环定义，不直接推出所作区分没有意义。
- 休谟的归纳问题不等于否认一切因果关系。人物之间的类比也不当作同一命题的证明。
- 海森堡处写位置与动量的统计分散，不说观察者创造世界，不把不确定性全归因于仪器粗糙；西田的问题也不改写成日语版蒯因。
- 恢复旅行、语言、哈佛教学生涯等人物生活，结尾让蒯因自己的粉笔线也能够接受追问；修改界线不等于抹掉同意与强迫的差别。

主要核对资料：[《经验主义的两个教条》](https://www.ditext.com/quine/quine.html)、[《回顾两个教条》出版页](https://www.cambridge.org/core/journals/canadian-journal-of-philosophy/article/abs/two-dogmas-in-retrospect/625219F55E27A4AED0EF2DCBF66F003A)、[卡尔纳普原文](https://ditext.com/carnap/carnap.html)、[格赖斯与斯特劳森原文PDF](https://sites.ualberta.ca/~francisp/NewPhil448/GriceStrawsonDogmaDefense56.pdf)、[哈佛纪念记录](https://news.harvard.edu/gazette/story/2002/05/faculty-of-arts-and-sciences-memorial-minute-6/)、[哈佛讣告](https://news.harvard.edu/gazette/story/2001/01/quine-92-was-major-philosopher-of-20th-century/)、[休谟《人性论》相关段落](https://englishphilosophy.org/hume/thn/1/4/7)、[Busch、Lahti、Werner关于不确定性关系的论文](https://arxiv.org/abs/1312.4392)。1991年出版页未提供本轮可读全文；温和整体论核对使用了[PhilArchive所收同篇论文](https://philarchive.org/archive/QUITDI)的检索摘录，不声称通读该文。

### 054 特斯拉

九节顺序：白鸽 → 电机与许多人的手 → 合同和后来的传说 → 沃登克里弗 → 爱迪生与商业组织 → 账本不能决定人的价值 → 康托尔及不同的困境 → 居里与不同的风险 → 旅馆、桥头和仍在运转的电机。

- 喂鸽开头标明想象；特定白鸽的回忆来自奥尼尔后来的记述，不写成已实测发光现象，也不把1922年故事安在1933年才入住的旅馆。
- 五万美元奖金故事区分特斯拉1919年自述中的经理，与已核实的爱迪生本人合同。
- 分开1887年专利申请和1888年授权、许可。保留多相感应电机贡献，也保留西屋、工程师、制造与配电系统的工作，不让他独自发明全部交流电。
- 早期交流输电优势不变成直流电永远无法远距离输送；保留现代高压直流这一边界。
- 尼亚加拉1895年发电与1896年送达布法罗分开，后者约32公里，不写成数百公里。
- 版税合同变化与后来撕合同传说分开；经济困境既不自动证明纯洁，也不能否定已完成的工程。
- 1901年摩根投资无线通信，与更宏大的全球无线输电计划分开。输送能量不是创造免费能源；1917年塔被拆毁不自动证明技术成功遭到阴谋压制。
- 爱迪生既是发明者也参与商业组织。电椅相关人物和作用不压成一个无所不能的反派；特斯拉1917年获爱迪生奖章，也说明他并非始终无人承认。
- 1943年最高法院判决涉及具体权利要求及特斯拉、洛奇、斯通等先前工作，不是宣布特斯拉独自发明全部无线电，更不是认证全球无线供电。
- 图灵遭受的迫害、康托尔的疾病和特斯拉的经济处境不能被归成同一种悲剧；不以受苦排序人物价值。
- 1856年出生地写当时奥地利帝国、今克罗地亚，出身塞尔维亚族家庭。1943年1月7日去世、86岁及房间编号分别核对。
- 身后保管材料的是外国财产管理机关，不写成FBI扣押材料已证明存在可用“死亡射线”。

主要核对资料：[特斯拉《我的发明》](https://en.wikisource.org/wiki/My_Inventions)、[奥尼尔1944年传记](https://www.rastko.rs/istorija/tesla/oniell-tesla.html)、[卡尔森传记出版社导论](https://assets.press.princeton.edu/chapters/i9941.pdf)、[特斯拉科学中心塔史](https://teslasciencecenter.org/history/tower/)、[尼亚加拉工业史](https://www.discoverniagara.org/harnessing-power-and-industry)、[1943年判决](https://supreme.justia.com/cases/federal/us/320/1/)、[FBI关于材料归属的说明](https://archives.fbi.gov/archives/news/stories/2008/july/myths_072408)、[特斯拉博物馆身份档案](https://tesla-museum.org/en/legacy/archive/identity-documents/)、[富兰克林研究所档案说明](https://fi.edu/en/science-and-education/collection/case-files/nikola-tesla)。出版社PDF是导论，不声称通过它通读卡尔森全书。
