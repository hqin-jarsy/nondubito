## 三、源稿核查优先项

这里区分“本地即可看出的矛盾／过强表述”与“尚待原典确认”。不把文学类比、作者读法本身判为史实错误；但新增语言不能把这种读法进一步译成确定事实。

| 篇目 | 升级前最需要处理的问题 |
|---|---|
| 老子 | 先承认身份不确定，后称“守藏室之史”为确定信息，证据层级不一致；档案包含三代全部记录及因此形成循环思想是强因果推想。出关、函谷关、青牛、孔老相见应区分《史记》记载与后出传统。郭店简释字／断句、“有无互相生成”的结论及《道德经》成书分章史，需原典／文本研究核对。 |
| 孔子 | “从未写任何东西”“没有一个国君愿用”“颜回是唯一理解者”“最后一句关于自己的话”等全称、时间与内心断言需收紧。中文将“天何言哉”归到庄子而英文无此归属，是双语差异核查重点。五组问仁的章句、颜回死与凤鸟不至的先后、《韩非子》八儒与第一代弟子的对应不能靠串讲自动成立。 |
| 苏格拉底 | 精确投票数、量刑时是否另提罚金，直接影响“拒绝所有替代方案”的叙事。临终段需区分《斐多》与《申辩》场景，避免把无梦睡眠／与荷马交谈合成同一天对话。“最后一天一直笑”“无人笑”“永不给答案”、柏拉图因悲伤才建理型论，均需将记录与作者设想分层。 |
| 王阳明 | 五溺、格竹、道观与僧人故事、追杀／投江／石棺需追《年谱》《传习录》等，标传记叙事而非逐句实录；“落井孩子”与孟子材料的归属需核。兵力、35 天、十家牌法及临终话核原典。正文“康德一辈子未离开柯尼斯堡”与康德篇记其乡间家庭教师经历存在跨篇冲突；与康德“完全相同的翻转”、军事胜利“验证”哲学，须明确是作者比较。 |
| 康德 | 第 138 / 360 行中英均写“1791 年重新发现，那时拉普拉斯已于 1796 年发表”，是文本内可确证的时序矛盾。出版商骗保纵火、全版销毁、求婚轶事、学生职务及潮汐减速优先权需证据。普遍化测试被简化为“大家都做世界还能运转就做”，以及东西方“同一幅图景”，不宜当作无争议的康德定义。 |
| 尼采 | 正文把都灵抱马写成精确实录，又以“不是疯了／自我涵育的物理极限”解释疾病；注释却承认病因不能确定，正文与注释证据口径不一致。十一年“沉默／坐在魏玛／什么都不知道”绝对化且地理时间待核。19 岁发文、Salomé“第一位女性精神分析学家”、精确求婚／性史／刺胸等应核；已有注释明确争议的，正文必须同步体现，不再把理论因果盖在医学不确定性上。 |
| 庄子 | 《史记》传记“不足两百字”及“全部可靠信息”需核；由任漆园吏推出唯一任职、必已离任且终身未返，是从史料沉默作肯定。梦蝶的 A／非 A 不当然构成逻辑否定关系，“物化真正含义”“惠施逻辑把世界切碎”等是本文阐释；不能译成原典唯一含义。寓言角色的言行不等于已证实的庄子生平。 |
| 释迦牟尼 | 生卒估计、释迦族政治制度与净饭王是否民选，不能从“并非绝对君主”直接推到“相对平等共和国”的确定图景；四门游观移植史、两导师／六年苦行／结集与分裂先后待核。原稿“筏过河后放下”被推成“摧毁整套教法”，需与筏喻上下文区分；英文 Burning the Bridge Behind You 还有断绝退路之意，不是筏喻的自然等义表达。涅槃与康德目的王国应标作者类比。 |
| 耶稣 | “尴尬标准几乎保证真实”“学者近乎一致认马可最接近历史”过强，不能代替逐处证据。三年传道、钉入手腕脚踝、九时至十五时应标经文／传统来源；行淫妇人、赦免语、流血汗的文本见证与异文需核。“系列唯一被暴力处死”紧接苏格拉底国家处刑对比，不宜保留字面全称。保罗“几乎只谈死与复活”、彼得／雅各争论、尼西亚相隔“两百年”及把犹太传统概括为假虔诚，须更准确且避免宗教刻板化。 |

共同规则：凡跨人物回指“从未离开城”“十一年不能说话”“笑着喝毒酒”，需一次核准后统一传播，不应在各语言、各篇重复放大。传说用“传统记述”；思想推演用“本文把它读作”；虚构相遇用“让我们想象”，无需把散文改成每句脚注。

## 四、下一批 001–003 的内容 coverage 清单

这不是摘要草稿，而是新语言稿的逐节验收底单。允许语言自然重组、合理拆合段落；不允许只剩人物标签、哲学口号与一句桥的结论。原文专门术语如需去术语化，应改写成能展开的关系和动作，而不是删除该段论证。

### 001 老子：九节完整链条

1. **守藏室**：身份不明与《史记》三个候选；档案员形象如何引出秩序兴亡与循环观察。历史资料与作者想象分开。
2. **道**：第一章核心意义；命名与恒常之道的距离；以语言说明语言的限度；“既不可说，为何还说”必须通向下一节。
3. **出关**：尹喜留人求书，上下篇五千余言，留下文字而自己离去；保留留下／离开动作及与苏格拉底、孔子的对照，注明传统叙事。
4. **龙**：孔子问礼、老子批评其骄气欲望与姿态；鸟、鱼、兽、龙的层层比喻；礼乐之网无法尽包另一人的作者读法。
5. **反**：转成对立面与返回两层；柔弱、水石等具体形象；郭店版本问题核准后保留其争议意义，接回档案所见的兴亡循环。
6. **有与无**：必须保留车轮、陶器、房屋三个器物，不只说“空无很重要”；实体边界与空处如何共同成用；与庄子凿混沌的比较。
7. **不可说与不可知**：康德的认识限度与老子的命名限度；同样触及边界，却一个留下建造、一个离去。不能合成“东西方思想一样”。
8. **道生一**：生成链、阴阳与冲气；与庄子的不同方向；解释老子一方面说生成、另一方面不住在自己言说中的张力，不保留只有行家才懂的维度标签。
9. **七个人与离去**：保留七人姿态蒙太奇：苏格拉底／孔子／尼采／康德／王阳明／庄子／老子各自面对边界。最后集中到五千字、青牛、去向不明，再反转为后人分章、立教、盖观，而他已不在；涉及成书史的事实措辞先核。

叙事边界：老子篇**没有独立桥上相遇对话**。要保留的是姿态蒙太奇、青牛离去和身后制度化的反转，不能为满足“桥头场景”自行编造九人会面。

### 002 孔子：八节完整链条

1. **丧家之犬**：旅途走散、旁人观察、子贡转述、孔子笑着承认；全文从这个“笑”出发，不缩成一句失意传记。
2. **述而不作**：口述教学、述与作、老彭及身份政治；旧礼乐中已有道路、工作是重新发现的自我定位；典籍整理事例保留但事实归属先核。
3. **问仁**：苏格拉底主动找人与孔子等待学生临界状态的对照；保留五位对象与五种答法：颜回、仲弓、司马牛、樊迟、子贡。不同回答如何让不同的人有所领会，不压成“因材施教”四个字。
4. **予欲无言**：孔子欲不言、子贡担心如何传述、四时百物运行的回答；终身言说与无言理想的张力；与苏格拉底无知的呼应。
5. **颜回**：三月不违仁与无所不悦的章句；死亡、痛哭、劝止、孔子回应及天丧予；保留关系损失，不只说“弟子死了他很伤心”。“唯一理解者”改作有出处限定的本文读法。
6. **知我者其天乎**：凤鸟河图与秩序恢复愿望；不怨天不尤人、下学上达；理解从同时代人转向天的情感走向，不把章句编排伪装成年谱。
7. **儒分为八**：《韩非子》引文及后学不同方向；每人承继不同部分，与柏拉图集中建造相对照；谱系核准后才解释东西方后续发展。
8. **两片空地**：雅典集市与春秋官道旁并置；苏格拉底的拆、孔子的挖；两次笑、两种等待。最后必须落在“颜回懂了，但颜回先走了”的缺席与失落，而非笼统殊途同归。

叙事边界：孔子篇**没有两人真正相遇、握手或对话**。末节的戏剧是两片空地并置，不应改造为新的桥头会面。

### 003 苏格拉底：八节完整链条

1. **自然哲学家**：早年自然研究、阿那克萨戈拉的心灵论带来期待、具体物质解释使其失望、“第二次航行”；叙事归属《斐多》，与历史人物完全等同需谨慎。
2. **神谕**：凯勒丰问神谕、苏格拉底不解而验证；政治家、诗人、工匠三组不同的自信与限度，不能只剩“知道自己不知道”。
3. **问题**：四部对话、四个问题；至少保留虔敬／神意与勇气／撤退等反例，具体展示问答如何拆动定义；再解释作者所说的空地。
4. **雅典受不了**：三名起诉者、正式指控、战争与三十人背景、克里提亚斯／阿尔西比亚德及大赦；历史信息和关于城邦心理的推想分开。
5. **申辩**：不走常规求情路径；旧喜剧偏见、神谕、牛虻、未经审视的生活；定罪与量刑两个阶段、公共食堂提议和原典中的其他提议；不能为制造姿态而省去罚金问题。
6. **毒酒**：克里托的逃亡安排与拒绝；法律理由与作者关于自我完整的解读；灵魂讨论及其不确定性；狱卒、朋友劝延迟、饮药、哭泣、安静、麻木、躺下、蒙面又揭布、欠医神一只鸡。具体动作必须核《斐多》后保留；尼采的“死亡是痊愈”与本文还债／感谢读法并置，而非宣称唯一解释。
7. **没有人笑**：柏拉图缺席、哭与笑的作者观察、如果有人理解而笑的反事实；从难以承受空地引向柏拉图及后续建造。情感／思想成因明确是作者解释，不当心理史事实。
8. **五个人／桥前空地**：康德和王阳明在桥头，尼采由另一端走来，庄子在桥下水中；苏格拉底不在桥上也不在水里，而在**造桥之前的岸边空地**。他问是否确知对岸，无人回答；逐一回到其他人的方向，最后回到他等一个笑的人。

叙事边界：本篇的桥头布景是思想性虚构，应轻量明示。苏格拉底恰恰没有加入桥头队列；空间位置本身就是论证。不得用“一行哲人站在同一桥头”抹平。

## 五、稳妥升级顺序与完成标准

建议按 canonical 分三次交付：**001–003 → 004–006 → 007–009**。每次三篇，但每篇先完成一个已核准的 coverage 底稿，再并行六语言；不要先一次生产 54 篇后补审。

1. **源稿预检**：先核该三篇的引文、年代、传说、场景归属与全称判断；决定中英差异中以哪一项为准，形成短的共同事实口径。未获正文修订授权时只记录，不擅改原文。
2. **数据接入**：第一乐章需新建明确的 JSON 来源或等效可重建数据，保留 canonical 原始路径映射（四篇在 `essays/` 根目录）。用正文来源与版本状态区分“旧简版”“已核完整稿”；不能以页面存在或翻译进度满 108 代替完整状态。
3. **逐语言完整写作**：保留原稿 8–10 节的论证与叙事功能；繁体也交完整正文，不沿用八段简写。自然译写不要求中英段数逐一相等，但不能省去人物、实例、推理转折、反例或结尾镜头。尼采是三个人与关系／制度论述，不宜改成普通尼采小传。
4. **专门检查结尾与回指**：保留每篇原有的桥、空地、水、离去和缺席位置；不存在会面便不补会面。王阳明等篇的“上一篇”、庄子的“前三个人”反映旧写作次序，与 canonical 不同；最好改成明确姓名或“前文相关篇”，不能挪动整组顺序迁就旧回指。
5. **双重验收**：结构测试检查非空章节、段落、六语言存在、canonical 导航、可重复构建；人工 coverage 逐项勾选事实场景、论证、类比声明、结尾。词数仅作过短预警，不把跨语种字符比率当精确保留率，也不规定每节只能一段或每篇只能八节。

当前最有价值的下一步是先冻结 001–003 的事实口径，再开始三篇六语言写作；不是先把现有四节短文扩成更多空泛段落。
