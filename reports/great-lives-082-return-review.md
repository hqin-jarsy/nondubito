# 082 屈原交回稿：质量评估，尚未接入

日期：2026-09-25。评审对象为名人系列目录下082 QuYuan v0.1八语言包，非对网站旧版本的总评。中文正文通读，其他语言仅结构检查与抽读；没有完成八语言母语终校或楚辞版本学复核。

## 结论

可用的完整底稿，需要一轮中等幅度的散文化编辑，不需要重新立论或退回重写。八语言均八节，完整性明显不是主要问题。此次不替换网站屈原页。

## 值得保住

1. 第三节把“朝”“夕”、露与花换成“美德”之后损失什么，讲得具体。这是“美参与认识”最好的大众入口，比反复宣告美是一种认知更有说服力。
2. 渔父有自己的歌和生存问题，不只是屈原的反面。坚持与应变之间没有替读者判定唯一赢家。
3. 没有把死亡当成作品流传的必要条件，或用成就反过来证明苦难值得。诗人与后世读者各有自己的工作。
4. 结尾兰草随水漂去、人物留在岸上，有独立的文学力量。它必须保持明确的桥头寓言身份，不用来改写传记，也不替真实屈原补签一个正确选择。

## 主要编辑点

- 第一、二节常先反驳旧稿才进入作品，例如“不能把……全塞进同一段”“不是中国文学第一次出现我”。读者没见过旧稿，这些段落容易像勘误。正文直接写可成立的情境与文本，出处争议集中到注释。
- 第四节的“认”、余项与程序选项表，把已经由诗建立的经验又翻译回体系语言。宜以求索、回望、依恋与选择继续展开，将框架说明缩短或后移；不是删去思想。
- 第五节应保留拒绝美化死亡的核心，但不用逐一驳斥漂亮旧句、节日单一起源和全部错误时间线。避免在写屈原时让核查本身变成主角。
- 第六节跨人物比较要控制长度。图灵的时间线有必要准确，却不必占据过长的纠错段；比较应服务于如何看待人，而非人物清单。
- 桥头中的“孔德原本承认诗”“这不是实验结果”等旁白仍偏多。读者知道这里是寓言之后，可以让合上日历、挪出干燥处、听见渔父的歌这些动作承担意思。

建议先精修中文与英文，再同步其余语言。保留第三节与渔父段的具体性，不把全篇改成统一格式的哲学总结。新稿可在上述编辑后进入完整稿升级，不必另开一轮大型重写工程。
