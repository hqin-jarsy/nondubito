# 《千与千寻》五语重写

本包收录秦汉（Han Qin）《千与千寻》三篇电影评论的德语、法语、西班牙语、日语和韩语独立重写，共十五篇。每篇都以完整中文原作为内容依据，以目标语言重新组织自然的表达；不是英文版的转译或摘要。

从[五语完整目录](INDEX.md)开始阅读。每种语言各有三篇，按原系列顺序排列：

1. 签下名字的那一刻，她就不叫荻野千寻了
2. 无脸男手里全是金子，可他什么都没有
3. 她记得自己的名字，也替别人记住了他的

目录保留了系列的完整导读、三篇标题与简介。正文保留原作者的论述、场景、提问、反复与跨篇呼应；作品解读仍是作者的解读。人物说话的文字依中文论述重新表达，不冒充各地官方配音或字幕。

本包依据的来源日期为2026年8月28日，源页于2026年10月5日读取。原作网站及原中英文版本未作修改。几处已核实的局部场景顺序、说话人及措辞问题，在新版本中作了最小修正；具体范围与中英文原作建议见[中文校订说明](中文校订说明.md)。尚不能确认的细节只列为建议，不据此删改论点。
