## 底本与译法

简体以本次用户所附《第八十四回　昧心人偏办昧心事　鸳鸯女终全鸳鸯誓》为唯一底本，仅按作者确认，将鸳鸯一句改为“我就得乖乖去给那黑心的忘八羔子做小老婆？”，其余正文未改。繁体与简体同稿，转换后按语境复核。六种外语逐段完整翻译，保持原有叙述次序，不把情绪留白补成心理说明。

人物及地点名称以实际已上线第81—83回为连续性依据。未在这些页面出现的名称在词表注明，不冒称已由既有译本核定。英文承接项目既定命名体系；译文是本次原创续作的翻译，不是任何已有译者的作品。

原文中有关婚姻、服制、人物指控和死亡的叙述按小说原貌保留；译者未据此替作者增添史实判定或情节解释。宝玉婚配对象在本回末仍未点明。
