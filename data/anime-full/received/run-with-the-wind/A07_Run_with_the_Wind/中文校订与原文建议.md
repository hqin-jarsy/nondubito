# 《强风吹拂》五语重写说明与原文建议

本包依据简体中文原作，分别为德语、法语、西班牙语、日语和韩语读者重写五篇全文。既有英文版仅用于对照，没有作为内容上限。2026年10月5日，经作者确认，五语正文采用了以下局部事实修订。人物话语仍是文章中的独立转述，不标作官方字幕。

网站、中文原作和既有英文版均未修改。未涉及本次修订的论证、场景与措辞保留；“无人能替另一个人跑”的主轴，以及对招募、照料与隐瞒不下最终裁决的立场，也予以保留。

## 一 已按作者确认落实的三项修订

### 第一、四、五篇：司法考试已通过，生活仍有自己的重心

[动画官方人物介绍](https://kazetsuyo-anime.com/character/07.html)说明，岩仓雪彦在三年级已经一次通过司法考试。五语人物介绍现改为已经通过，而不是正在备考。

欢迎会、时间安排、个别化训练及末篇“原有生活没有消失”等相关段落，也同步改写：保留他的法律学业和后续职业方向仍需要时间这一优先级，不再以“推迟司法考试”“为司法考试熬夜”或“考试日期不会推迟”为论据。没有只修正人物介绍，却在后文继续保留未通过考试的前提，也没有编造新的考试、录用或职业承诺。

### 第一、四篇：长期准备不等于所有人共同生活多年

灰二的准备持续多年，但走刚刚入住；[城太郎](https://kazetsuyo-anime.com/character/03.html)与[城次郎](https://kazetsuyo-anime.com/character/04.html)在动画官方资料中是一年级。五语现在区分三层时间：灰二长期准备、较早住户多年积累的关系，以及新成员进入已经建立的日常安排。

“多年吃他做的饭”“摸清作息与身体”“搬走等于退出多年关系”等表述，都明确其适用于较早住户的范围。走的最初身体判断仍来自那一夜的短暂观察。长期照料与动员共用同一份了解的论点保留，不再把九个人写成在同一段多年观察中一并长成。

### 第五篇：八次现场交接，隔夜继续

箱根是两日比赛：往路四次现场交接，第五棒抵达首日终点；次日第六棒重新起跑，复路再有四次现场交接。[动画第21话官方梗概](https://kazetsuyo-anime.com/story/21.html)也明确写到由纪准备复路起跑、神童在旁，以及上午八时复路开幕。

五语已联动修改开头、赛程展开与结尾的重复计数，写成八次赛道上的交接和隔夜继续。结尾“中间八人”也明确第五棒在首日终点停下，没有一位第六棒在他抵达的同一刻立即出发。十个人必须各自跑完十段路、任何人都不能替别人承担那段身体上的奔跑，这个论证未被改动。

各语言的系列简介与目录也已核对；其中没有依赖未通过考试、人人多年同住或九次现场交接的说法，因此没有额外改写。

## 二 襷装饰的旁证仍只在说明中保留疑问

原文称“很多队伍”会在襷上缝护身符、字与前辈记号，需要明确它指的是作品内的具体画面，还是对现实比赛的概括。[箱根官方竞赛实施要项](https://www.hakone-ekiden.jp/_assets/2024/69e4afd8b48cae01aa41d6a429007c3a14b5d38d.pdf)对襷的标记有严格限制，但现实规则不能单独证明虚构场面不存在。

本次没有据规则自动删改五语正文中的这个例子，也没有擅自断言动画中确实出现了该画面。它作为尚需补充作品出处的旁证问题，在此说明；与上述已经确认并采用的三项事实修订区分开来。

## 三 先前已采用的最小整理

- 双胞胎的年级依动画官方人物资料改为一年级；多年共同生活的范围现按上节所述，随作者确认作了联动修订
- “九个从未跑过的人”等明显扩大范围的句子改为经验较少、以初学者为主的队友；灰二和尼古前辈不能被一概说成从未跑过
- 绰号、校名与宿舍名按各语言习惯统一；日语使用蔵原走、清瀬灰二、寛政大学、竹青荘等原名，原文偶见的“青竹庄”统一为同一宿舍
- 提前出发写成未接到原来那条襷、改戴替代襷出发，不写成完全不带襷出发；未把一般赛制说明扩写成当代规则大全
- 灰二第十区写成返回东京的最后一段，避免误写他独自从箱根跑回东京；[官方复路路线](https://www.ntv.co.jp/hakone/coursemap_returntrip/)列第十区为鹤见至大手町
- 结尾“十个小时之后”整理为次日（部分语言同时保留累计十多个小时的比赛时间尺度），避免把两日赛程缩成同一天；“一百米都跑不动的人”明确为曾经跑不动
- 往路结束的交接人数表述避免暗示只有第五人曾经接到襷；不改变十人各跑一段的意思
- 第四篇相邻两次重复“方法是组织十个人跑一次箱根”的句子，部分语言合成一句；第二篇前后呼应的漫画描述与“不是被说服，而是认出”的反复保留

上述整理只涉及明确的人名、指代、年级、日历时间、路线和行文衔接。原文对灰二的强判断、对王子动机的并置、对走所持尺度的分析、对集体成果归属的判断，均未改成折中结论。

## 四 仍需留意的表述边界

第三篇称作品没有安排“走终于超越藤冈”的时刻，宜明确这是对叙事意义的判断，不宜读成否认两人区间成绩可比较。官方第23话梗概谈到藤冈刷新区间纪录和走的惊人速度，但梗概本身不足以解决文章具体要否认什么；本包保持原文的叙事论点，未添写赛事纪录结论。

第四篇膝伤的详细高中时间线部分来自小说。各语保留篇末的来源界限，没有把所有细节都当作动画画面，也没有另加医学诊断或预后。

第五篇“无人能替跑”不等于所有照护均被禁止。规则允许规定的补水及为确认状态、保障安全而进行的短暂接触；本包强调不能替人完成身体上的跑程，未另行削弱原文关于不可替代性的论述。

## 五 对既有英文版的建议

五篇英文版均明显短于中文，不能直接用作其余语言的内容底本。若英文也希望承载中文全文，建议逐篇补回具体场景和中间推导。

1. 《房租便宜是有条件的》：英文压缩欢迎会的各人事务、厨房谈话、身体观察和预选会的时间压力，并对后来的同意作了较明确的规范判断。中文的重点是把两个事实并置、不给最终裁决。建议补足细节，并确认英文是否有意走向另一种结论
2. 《三个理由》：建议补回各阶段“不曾发生”的完整清单、具体资格门槛、赛道上浮现的句子，以及扎头发这个微小的自主发现。“人的计划由世界中的材料构成”是英文展开的概括，不能代替中文在细节中收束的方式
3. 《他带着那把尺子进了大学》：英文开头把十三分五十秒级成绩放到入读高中时，中文是高二。建议先对齐时间；英文末节“强而不只是快”及秒表结论是另外的解释，不应掩盖中文不替变化命名的做法。还应补回榊、藤冈与走的具体对照及转入灰二旧伤的收尾
4. 《知道那条腿的人在对面》：英文第一节把尼古前辈的恢复安排与王子相比，中文比较对象是神童。英文又将后来的继续参赛解释为信息更充分后的新行动；中文列出原谅、来不及等可能，却不选定答案。建议纠正比较对象，明确是否保留这种解释差异，并补足无法替别人完成的教练工作与隐瞒之间的关系
5. 《没有人能替另一个人跑》：英文加入发烧的神童、每个人完整的内在赛段、共同所有权与暂时性的总结，同时省去了许多交接动作、球类对比、原有生活未被消除、成果最后一步之前尚不存在的推导。建议补全原作链条，避免用新增总结替换中文“需要每个人而不属于任何人”的强结论
