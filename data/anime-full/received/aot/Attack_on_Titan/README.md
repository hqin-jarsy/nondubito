# 《进击的巨人》五语解读集

作者：Han Qin（秦汉）  
中文原作发表：2026年8月28日  
本包收录五篇文章的德语、法语、西班牙语、日语、韩语独立重写，共25篇 Markdown 文件。

这五篇从墙内失忆与墙外规训，读到未来记忆、地鸣与尤弥尔，追问自由是否必须包含说“不”的能力。它们不把故事当成一道只须裁决艾伦对错的题，而讨论知识、出路、选择与拒绝如何被拿走，又如何可能重新出现。

全文包含漫画及TV动画结局剧透。每个语言目录都按EP01至EP05顺序阅读。文中人物发言为独立转述，不是官方字幕引用。中文、英文原文修订建议另见[中文备注](notes_zh.md)；源网站及原稿未作修改。
