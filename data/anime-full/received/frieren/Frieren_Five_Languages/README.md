# 《葬送的芙莉莲》五语解读

从葬礼上的眼泪，写到旧友留下的道路、魔族理解人类的限度，以及无用魔法中保存的记忆。内容包含动画及漫画后续剧透；第三篇主要讨论漫画“黄金乡”篇。

作者：Han Qin（秦汉）
