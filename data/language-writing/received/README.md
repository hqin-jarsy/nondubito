# 语言与写作 八语离线阅读包

作者：Han Qin（秦汉）。系列：把话说成自己的 / Finding Words of Our Own。

## 从这里开始

先完整解压 ZIP，再用浏览器打开 READ.html。页面为 UTF-8，正文和导航不需要网络或 JavaScript。HTML 采用设备已有衬线字体；不同设备显示可能略有不同。每篇可切换语言、进入上一篇或下一篇。MD 文件夹提供可编辑的 Markdown 文本。

## 收录范围

本包只收录《语言与写作》三篇文章的八种语言版本，共 24 篇，不是整个网站备份，也不包括系列首页介绍的八语翻译。

简体中文、繁體中文和 English 来自网站已有版本，标题、导语、正文与来源说明按原文保留；英文在原网站即为独立重写，不是中文逐句对照译文。Deutsch、Français、Español、日本語、한국어 为本次新增 AI 辅助译本，不应误认为网站已发布版本或作者审定版本。译文经过自审与全文复核；未经过母语者审校。文件与静态结构已核验，未进行浏览器视觉检验。

原文说明将文章定位为依据相应 SAE 论文改写的读者散文，不是论文的完整技术翻译；日常场景为虚构示例。各篇末尾保留相应阅读说明和实际引用来源。

## 日期与出处

网页抓取快照日期：2026-11-03（UTC）。这不是文章发布日期；网站原始发布时间及修改时间保存在原始 HTML 快照中。文章原网址及论文/参考链接见各篇末尾与 MANIFEST.json。外部参考链接需要联网，本包不含论文全文。

source-snapshots 保存抓取的原始网页为 .html.txt 文本，避免误打开时运行原网页脚本或加载联网资源；它们只用于核对出处，不是离线阅读入口。links.json 保存网站实际引用链接。

## 文件与校验

- READ.html：八语目录。
- HTML/：24 个独立离线阅读页面。
- MD/：24 个 Markdown 文本，正文后附来源说明。
- source-snapshots/：三篇文章和系列首页的原始网页文本快照及引用链接。
- MANIFEST.json：版本、来源、正文哈希及抽取核对结果。
- SHA256SUMS：除本文件自身外全部交付文件的 SHA-256 校验值。
