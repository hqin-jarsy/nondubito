# 《雾都孤儿》只读预核

审读者：moon。范围：essays/literature/oliver-twist 四篇完整中文及旧英文，原作重点章节复核。未改仓库，未 commit/push。此为事实审读清单，不是授权重写作者文学立场。

## 旧英文
四篇均为明显压缩稿，不能作为完整英文基础。须从中文恢复叙事、短段推进及论证，而非再扩写旧英文摘要。尤其第四篇旧英文侧重虐待关系/离开困难，未完整承载中文“不交换”的论证；新译应恢复作者这一读法，同时不以已被原文否证的情节作支点。

## 本轮新增确定修复

### EP1
- 医生并非“第一句话”就查看婚戒。第1章先安慰母亲不要谈死；母亲死后才问来历、看左手并议论没有戒指。最小改“医生临走前看了看她的左手，说……”；保留冷淡分类的批评，但不抹掉前面的安慰。
- 原作：https://www.victorianlondon.org/books/oliver-01.htm （安慰在母亲死前，无戒评论在死后）。

### EP2
- “费金不骗人”过强且与第9章直接相反。他称赃物是精巧手艺，说孩子可以学习制作手绢，Oliver真以为是制造业；另藏珠宝、举刀威胁后也掩饰。最小改“不只是骗人”：真实饭食、游戏、接纳，与欺骗并存。不宜保留孩子每一步充分知情自愿。
- 第9章：https://www.victorianlondon.org/books/oliver-09.htm 。
- Brownlow没有亲眼见“另一个孩子”行窃。他不确信Oliver偷手绢，承认因看见他跑而追，并请求如判同伙也从轻。书摊主才是证实另一个孩子行窃的目击者。最小修正两人证言分工，保留善意被法庭压制的论点。
- 第11章：https://www.victorianlondon.org/books/oliver-11.htm 。法官先要求赶走书摊主，后听证；没有找到“罚书摊主款”的情节。若正文写罚款，改成赶走即可。判三个月苦役后因证言释放，次序应保留。

### EP3
- Nancy首次出现是和Bet到费金房间，随后在那里喝酒，非第一次在酒馆出现（第9章）。删“酒馆”即可。
- 第13章Nancy起初拒绝去警局打探，Sikes与Fagin交替威胁、许诺和贿诱，才促使她去。她有行动能力，也参与迫害，但不能绝对断言无胁迫、全程自愿。最小写“她最终去了，而且演得逼真”；删“没有人逼她”一类事实否认，不把她一笔改成无责任者。
- 第13章：https://www.victorianlondon.org/books/oliver-13.htm 。
- Rose在旅馆见Nancy时还未见Brownlow；次日第41章才因Oliver发现住址而初访他。故“旅馆里的Rose背后已有Brownlow安排出国”混合了两个场面。旅馆安全住处提议属于第40章，国外庇护明确提议属于第46章桥上Brownlow。
- 第41章：https://www.victorianlondon.org/books/oliver-41.htm 。

### EP4（含影响EP3的会面叙述）
- 第40章Rose在Nancy尚未披露完整情报之前已愿帮助贫困/受苦的她；后来既以悔改与救Oliver来劝，又明确说不只为她自愿提供情报，也因为她是迷失的女人。因此“好人世界只肯因她做了好事才救她”不可当完整情节事实。保留“作者从救赎语言里读出交换框架”，但至少不抹去此前的主动怜悯。
- 第40章：https://www.sparknotes.com/lit/oliver/full-text/chapter-40/ （这里引用的是原著全文，不是学习指南）。
- Nancy明确谈到对Sikes的感情、没有家庭朋友的女人如何把一个男人当作全部；她也表达已被旧生活束缚。作者可认为这些并未解释尽她的决定，但不能把“完全没有解释”“确定不是爱”当作Dickens明写结论。
- 第46章拒绝的对象首先是交出Fagin；随后接受不未经她同意追究他的承诺，提供Monks线索。不是简单的“他们要求她出庭指控费金和赛克斯”。她拒钱，却主动求Rose一件贴身小物作纪念，不能说拒绝任何东西。
- 第46章：https://www.victorianlondon.org/books/oliver-46.htm 。可保留“不拿情报换自身获救”，不要把两次会面压为单次交易。
- 第47章Fagin说不要太暴力，紧跟着解释是为安全，要狡猾而非莽撞；不是叙述者写“这话是喊给自己听的”。最小写其劝阻关乎自保，不虚构叙述者评语。
- Nancy临死提议两人离开后各在远方过更好生活、永不再见，不是一起开始新生活。她也恳求救自己的命，同时求他悔改，不能断言只想他不想自己。最小保留“她在求生时仍给他指出回头路”，不要保留“共同未来”。
- 第47章：https://www.sparknotes.com/lit/oliver/full-text/chapter-47/ 及 https://www.victorianlondon.org/books/oliver-47.htm 。原作关键短语：far apart；never see each other more。手枪柄先打两下，再用棍棒杀死；Rose手绢与最后祈祷可保留。

## 与quality已确认清单合并（由父线程提供，不冒称全由本轮再核）
- EP1 甘菲尔德价已谈成3镑10先令，最后法官拒签，非因价谈崩。
- EP1 厨子用勺打、班布尔用杖打，不能说无人打他；每周两次洋葱，不是小面包。
- EP2 费金实际锁门，改成“不只锁门，也拆掉回去的桥”，不要用不存在物理禁闭支撑算法论。
- EP3 Nancy只送孩子到Sikes处，未参加入室盗窃。
- EP3 Charley Bates结局改过，不能说这些孩子无人会回头。
- Nancy“六岁开始”“二十几岁”无可靠原作依据；第16章仅说偷窃始于不到Oliver一半年龄，持续十二年。使用相对年龄/多年即可。

## 保留的解释边界
不将每个激烈文学判断都改为学术免责声明；非交换、共犯复杂性、制度分类及善意的局限都是作者可保留的立场。仅修确切事件、说话者、地点、先后、人物知情程度，以及直接依赖错误事实的绝对否定。较大的论证变化交父线程/作者判断，不能借翻译悄悄替换成另一篇文章。Sikes若被痛骂便不会内疚之类属于作者反事实推想，宜自然标为推想而非已证心理规律。

## 后续点核补充（父线程/作者指定）
- EP1 甘菲尔德曾打死三四个男孩是第3章传闻/指控（imputation、rumour），不是确定“刚刚弄死几个学徒”。最小写“传闻他曾打死三四个男孩”。 https://www.victorianlondon.org/books/oliver-03.htm
- EP1 母亲托保存遗物见第24章；第38章Sally已典当遗物，死时手握当票，Mrs Bumble赎回，不是一直藏着原物多年。多年续息是Mrs Bumble的推测。最小写“她偷走遗物，后来典当，临终留下当票”。 https://www.victorianlondon.org/books/oliver-24.htm 及 https://www.victorianlondon.org/books/oliver-38.htm
- EP2 第14章Brownlow交给Oliver五镑钞票，用于付书商四镑十先令欠款、带回十先令找零；但第16章被抓后Oliver确实求把书钱还给老先生，勿错误纠正后者。 https://www.victorianlondon.org/books/oliver-14.htm
- EP2 第16章Charley嘲笑新外套，Fagin附和；最后Charley拿出旧衣，命Oliver换掉新衣、拿去交Fagin保管。不是Fagin拿新衣展示。钞票由Dodger搜出、Fagin抢过、Sikes最后取走；可以简写众人搜夺衣物钱款而不误归具体动作。 https://www.victorianlondon.org/books/oliver-16.htm
- 历史背景边界：新济贫法的讽刺关联与小说全部情节确切发生在1834之后是两回事。尚未为后者找到证据，不以小说人物年龄反推具体历年。建议自然写作品回应新济贫法语境，而非断言具体情节时间。

## 修订中文全篇再读（502块）
已完整再读四篇修订中文。非交换的作者读法仍保留，新增爱/依附、Rose主动关切的事实没有把全文改成另一套心理解释。以下余项已交catch统一修改源和中繁，不并写正文：
- EP3零起61–63时序：第19章Nancy当面建议使用Oliver，参与筹划；第20章接人时说已尽力保护并展示瘀伤，不能确指筹划盗窃时她与两人争吵、因此被打。建议写“她曾挡过殴打；来接人时说已尽力、展示颈臂瘀伤”，保留送到Sikes处而未随同入室。原作 https://www.sparknotes.com/lit/oliver/full-text/chapter-19/ 与 https://www.sparknotes.com/lit/oliver/full-text/chapter-20/ 。
- EP3零起72/EP4零起29“好几次偷听”改“先后偷听”，原作关键是两次，不另添次数。
- EP3零起108–109下一次见面不是Rose/Brownlow事后召约；第40章Nancy已当场约定星期日桥见。建议“下一次会面，Rose带Brownlow来问清Monks；她按约来了”。
- EP4零起95见Sikes脸立刻明白告密败露不实：第47章先惊问，后被告知，改“惊恐地问出了什么事”。
- EP4零起11失踪必使对方知道告密是过于具体的虚构推理；可最小写她怕暴露、怕将牵挂的人送上绝路，衔接第40/46章实际担忧。
- 保留边界：费金“不享受作恶”、赛克斯“唯一纯恶棍”等仍为原作者文学判断，未擅自扩成全面人物改写；译文不要加强为原作旁白定论。
