## English

Eight complete illustrated editions of a close reading of Rembrandt's Self-Portrait of 1659. Each includes the full argument, localized captions and alternative text, source links, and an optional SAE section. Unzip without changing the folder structure and open the desired Markdown file in a reader that supports relative images and links. Images are shared across editions. The package contains no research PDFs or unlicensed comparison photographs.
