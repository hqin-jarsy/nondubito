# 中国书法细读 11 / Close Readings of Chinese Calligraphy 11

**《曹全碑》：伸长的一笔，靠什么站住**

Open `READ.html` in a browser. All eight complete articles (简体中文、繁體中文、English、Deutsch、Français、Español、日本語、한국어) are available as standalone Markdown and HTML. The four genuine rubbing photographs are embedded locally; each caption links to the official high-resolution viewer. The essays can be read offline, while the official links require internet access.

## Version and rights

Original stone: Eastern Han, 185 CE. Reproduced object: Palace Museum accession 新00045355, early rubbing after the Ming excavation, before the stone's fracture. This is not Han paper or a rubbing from the beginning of the Ming dynasty. See SOURCES and IMAGE_NOTES for details.

**No image republication permission has been obtained; no open license is claimed.** Further public or commercial redistribution requires separate rights clearance. The package contains only reading-size photographs, not the high-resolution masters or downloaded source-page texts.

## Rebuild and verify

Requires Python 3 and the Markdown package specified in requirements.txt. Run `python build.py` from this directory to regenerate all article HTML, READ.html, MANIFEST.json and SHA256SUMS.txt from the eight Markdown files and included images. Rendering uses no network. Image acquisition and transformations are fully described in IMAGE_NOTES and IMAGE_MANIFEST; the viewing files themselves are the local build inputs.

On systems with sha256sum, run `sha256sum -c SHA256SUMS.txt`. The manifest inventories only distributable reading files, not research downloads. Checksums verify file integrity, not historical interpretation or permission to reproduce images.

## Review status

All eight complete texts and the four reproduced images were checked for consistency, character locations and the distinction between the original stone and the later rubbing. Figure 4 consistently joins 神明膏 across columns, places 至 below 親 and 王 in the neighboring column, and does not interpret 七首 as an established count of seven prescriptions. See QUALITY_REVIEW.md for details.

Local image, HTML-structure, relative-link and checksum checks passed. Final browser layout has not been verified; static checks are not a substitute for browser inspection.
