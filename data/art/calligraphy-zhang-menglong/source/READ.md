## 重建 / Rebuild

成品 HTML 已生成，无需重建。要从 Markdown 再建 HTML，可在具备 Python 及 Markdown 包的环境中运行 python build.py。图片已经包含；download_images.py 是可选的源图裁切复现脚本，另外需要 Pillow 和网络。脚本不会安装软件。
The finished HTML files are ready to read. Optional rebuilding requires Python and the Markdown package: run python build.py. Optional image reproduction uses download_images.py with Pillow and internet access. Neither script installs software.

检查范围：HTML 静态结构、本地链接、每语四张图与文件校验值。未声称完成浏览器跨设备视觉测试。
Validation covers static HTML structure, local links, four images per article and file checksums. Cross-device browser layout testing is not claimed.
