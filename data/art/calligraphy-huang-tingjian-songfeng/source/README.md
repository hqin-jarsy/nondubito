# 《松风阁诗帖》八语图文版 · Read me

中国书法细读09，v1.0，2026年10月19日。作者：秦汉 / Han Qin。

从READ.html或index.html进入，选择简体中文、繁體中文、English、Deutsch、Français、Español、日本語或한국어。每语都有完整Markdown正文及对应HTML，含21句原诗、完整译释、五张保留邻列的局部图和本语图注。图片可点击独立打开；正文末尾的技术说明默认折叠。

本文主张是：长画向外伸出，并没有把整个字均匀摊宽。五、築、箕、舟、安等字让外郭与内部密度呈现两种尺度。可选附读实际参照秦汉射线10《“是我认错了。”》，讨论观看者如何校正“全字被拉宽”的初判。

## English

Open READ.html or index.html and choose a language. Each of the eight editions contains the full essay, all 21 original poem lines with a complete translation or modern-Chinese explanation, five contextual detail images, localised captions and a foldable technical note. Select an image to open it separately. The low-resolution orientation image covers only the opening and middle sections; it does not include the final section.

The photographs are from the National Palace Museum, Taipei. Source links, crop coordinates, credits and reuse terms are documented separately. The package is a local deliverable; it has not been published or deployed.

Local pages and images work without an internet connection; external source links do not. Static validation and direct inspection of the photographs have been performed. Browser screenshot testing was not performed because Chromium startup is restricted in this environment. No claim of desktop or mobile screenshot approval is made.
