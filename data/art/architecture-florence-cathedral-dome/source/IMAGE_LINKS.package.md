# EP17 官方图像外链

5幅图像均已实际观看。正式交付只保留下列官方外链，不附第三方图像文件。

1. 开篇：穹顶上半部与灯亭，背景山脊。
   来源页：https://www.feelflorence.it/it/punti-di-interesse/cupola-del-duomo
   直接图片：https://www.feelflorence.it/sites/default/files/styles/hero_landscape_internal_1x/public/2025-11/%C2%A9NicolaNeri527WEB_2NIK0187.jpg.webp?h=a1e1a043&itok=ba25YIfs
   版权：官方页列Comune di Firenze；文件名带©NicolaNeri。
   实看：白肋将红瓦分面，汇到灯亭底座；灯亭有竖窗、卷曲扶壁和尖顶，金球上部被画面裁掉；下部教堂不在画面内。正文不写在这张照片里看见全部八肋。
2. 地面仰视穹顶及鼓座。
   图像记录：https://brunelleschi.imss.fi.it/itineraries/image/img2833.html
   直接图片：https://vitruvio.imss.fi.it/foto/isd/mb/mb293-10_800.jpg
   摄影：Marco Berni / IMSS。
   实看：带大圆窗的八角鼓座有明显转角；红瓦与白肋在上部；前方较低的屋顶、墙面几何装饰；灯亭大部分被自身穹顶遮住。画面右上可见历史修护架，未写成当下施工。
3. 1757年大教堂平面与横剖面。
   图版记录：https://brunelleschi.imss.fi.it/itinerari/immagine/img5119.html
   直接图片：https://vitruvio.imss.fi.it/foto/isd/icona/icona26344_800.jpg
   来源：L. Ximenes，Del vecchio e nuovo gnomone fiorentino…，Firenze，1757；IMSS / Franca Principe。
   实看：右侧长中殿通向八角中央与三向端部；左侧横剖面有内外穹顶轮廓、鼓座圆窗、下部拱和太阳光路线。图的主题与时代明示，不能当布鲁内莱斯基原始设计图。
4. 白色主棱和屋瓦高处近景，远处街屋。
   图像记录：https://brunelleschi.imss.fi.it/itineraries/image/img2190.html
   直接图片：https://vitruvio.imss.fi.it/foto/isd/mb/mb95-05-12_800.jpg
   摄影：Marco Berni / IMSS。
   实看：宽阔白肋有上面、曲折边缘、侧面、石块接缝；右下红瓦有偏橙、偏褐的小幅色差，搭接处留有深暗细边；红瓦跨越近景，街屋在下方。图含博物馆原水印，未去除。正文明确屋瓦不是内部鱼骨砌砖。
5. 穹顶起脚部位脚手架支座。
   图像记录：https://brunelleschi.imss.fi.it/itineraries/image/img2186.html
   直接图片：https://vitruvio.imss.fi.it/foto/isd/mb/mb95-05-05_800.jpg
   摄影：Marco Berni / IMSS。
   实看：红瓦下方粗砌墙带有连续外凸石支座，下方是几何大理石饰面。支座用途依博物馆图注，不凭形状自定年代或用途。

材料范围：正文模型段依据官方文字说明；未把未见到的模型照片、内壁画照片列作观看依据。
