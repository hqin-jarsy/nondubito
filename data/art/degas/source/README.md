## English note

This package contains eight complete Markdown essays and five shared official photographs of the same original wax-and-mixed-media sculpture, NGA accession 1999.80.28. Keep the images folder beside the essays. Image credits, source links, pixel dimensions and checksums are included. The approved simplified-Chinese text remains unchanged from version 0.2. No posthumous bronze photographs have been substituted.
