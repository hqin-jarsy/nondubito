Decker 与那些无法命名的作品

Decker and the Works Without a Category

Han Qin (秦汉)

Decker 是 Internet Janitor（约翰·厄内斯特）独立开发的多媒体创作工具，精神来源于1987年苹果公司的 HyperCard。它的核心约束是"ditherpunk"：纯粹的1-bit黑白抖动，拒绝颜色渐变与现代图形效果。用户用内置的绘图工具、一种叫做 Lil 的脚本语言，以及可编程的声音接口，构建一张张"卡片"，再将其串联成可在浏览器中运行的自执行HTML文档——不依赖外部服务器，不需要账号，不带广告与追踪。每一个"Decker作品"都是一个完整、可离线运行的小宇宙，可以在任何地方分享，也可以永远自给自足地存在下去。

Decker 的余项性在于它无法被任何现有类别充分描述。它不是游戏引擎：虽然用它做的游戏在 itch.io 上有数百件。它不是网页工具：虽然它的输出是标准HTML。它不是复古计算实验：虽然它的界面让人想起1988年的麦金塔。它不是电子杂志平台：虽然有人用它出版折叠式zine。在SAE的术语框架里，这四个领域都已经是"已构"——是被艺术世界和技术世界充分命名的领土。但 Decker 恰好生长在这四者之间的裂缝里，而那个裂缝本身，就是今天的余项。更具体地说：那个1-bit约束不是限制，而是一把凿子。它问：如果没有颜色、没有渐变、没有现代图形，人们还能表达什么？那个问题的答案正在以每一件新作品的形式成为新的已构。凿构循环还在运转，而裂缝还没有被填满。

今年7月整个月，Decker Fantasy Camp 2026 正在进行（截止日期为8月1日）。目前已有80名参与者、33件提交作品。这些作品的多样性令任何分类尝试都陷入困境：有一个用文字描述当前时间的时钟（"Half past eight"），有一个鼠标控制的噪音玩具（"Janky Theremin"），有一个十九世纪折叠玩具剧场模拟器（"The Tiny Toy Theatre Imagination Kit"），有一个围绕 Amen 鼓点构建的鼓机，有一个关于"我珍视之物的身后事"的互动指南，有一个滑板个性问卷，有一件个人告白式的短篇互动文学。每一件作品都不完全属于任何一个已有类别，因为 Decker 的约束强迫它们成为只有 Decker 才能产生的东西。在凿构循环的意义上：这个工具正在以社区的方式持续凿击，而那些凿出的碎屑——那些无法被命名的作品——就是当下的余项之美。

还有一个细节值得关注：Fantasy Camp 的规则明确禁止使用生成式人工智能工具。这不是偶然——Decker 的整个美学，本就是对"无摩擦生成"的一种静默抵抗。它要求手工构建，要求在约束中思考，要求接受那些因1-bit限制而无法完成的事情。在所有工具都在加速走向自动化的时刻，一个刻意选择慢下来、选择约束的工具，占据了一个没有其他工具愿意占据的位置。那个位置本身，也是余项。艺术世界尚未为"Decker作品"建立一个类别。那个类别的缺席，正是此刻看它的理由——在它被命名之前，在它的逻辑停止生长之前。

Decker is Internet Janitor (John Earnest)'s independently developed multimedia authoring environment, spiritually descended from Apple's HyperCard (1987). Its defining constraint is "ditherpunk" — a pure 1-bit black-and-white dithered aesthetic that refuses color gradients and modern visual effects. Users build stacks of cards using built-in drawing tools, a Lua-like scripting language called Lil, and programmable sound interfaces, then export finished decks as self-executing HTML files that run entirely in the browser — no accounts, no ads, no telemetry, no server dependency. Each Decker work is a complete, portable, offline-capable artifact: shareable anywhere, self-sufficient indefinitely.

What makes Decker structurally 余项之美 is precisely its categorical unresolvability. It is not a game engine, though hundreds of games have been built with it on itch.io. It is not a web publishing tool, though it outputs standard HTML. It is not a retrocomputing nostalgia project, though its interface evokes a 1988 Macintosh. It is not an e-zine platform, though foldable printable zines emerge from it regularly. In SAE terms, each of those four territories is already-construct — fully named, institutionally recognized, with its own critical vocabulary. Decker grows in the gap between all four, and that gap itself is the remainder. More precisely: the 1-bit constraint is not a limitation but a chisel. It poses a question: what can people express when stripped of color, gradient, and contemporary graphic conventions? The answers — each new submission — are in the process of becoming new construct. The chisel-construct cycle is still running. The gap has not yet been filled.

Decker Fantasy Camp 2026 has been running all of July, closing August 1. Eighty participants, thirty-three entries so far. The range of work defies any coherent taxonomy: a clock that tells time in words ("Half past eight"), a browser-playable janky theremin operated by mouse movement ("Janky Theremin"), a Victorian toy theatre diorama simulator ("The Tiny Toy Theatre Imagination Kit"), a drum machine built around the Amen break, a guide to the posthumous fate of prized possessions, a skateboarding personality quiz, a short personal interactive vent piece. None of these works fits cleanly into any pre-existing category, because the Decker constraint forces them into a form that only Decker can produce. In the language of the chisel-construct cycle: the tool is continuously chiseling through its community, and the fragments — the works without a name — are the current beauty of the remainder. The art world has not yet built a category for "Decker work." That categorical absence is the structural signal: the remainder is still alive, still growing, not yet settled into construct.

One further detail worth marking: the Fantasy Camp rules explicitly prohibit generative AI tools. This is not incidental. Decker's whole aesthetic is a quiet resistance to frictionless generation — it demands hand-construction, demands thinking-within-constraint, demands accepting what the 1-bit limitation makes impossible. In a landscape where every tool is accelerating toward automation, a tool that deliberately slows down, that insists on constraint, occupies a position no other tool currently claims. That position is itself a remainder. The moment to see it is now — before the art world catches up with a name for what's happening here, before the logic stops growing.
