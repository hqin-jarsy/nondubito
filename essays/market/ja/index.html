Non Dubito · 市場について

市場：最低限の境界を守り、選ぶ余地を残す

価格は生まれる。だが、すべての人に代わって答えることはできない。売買、関門、競争、資金から、市場の境界、選択、問いかけを読む九篇。

9篇 · English / 简体中文 / 繁體中文 / Deutsch / Français / Español / 日本語 / 한국어

シェルターの外から始めよう。価格を決めた唯一の人はいなくても、目の前の人には今夜のベッドと、自分で歩ける道が必要だ。

01

市場には、呼び出して話せる顔がない

価格を決めた一人が見つからなくても、問いかけられる制度がないわけではない。生活の最低限を守り、試みる余地も残す。

全文を読む →

02

一か所を離れた後、その介護はどこにあるのか

保障が受け止めるのは供給であって、特定の機関ではない。退出できても、その先の生活条件への答えにはならない。

全文を読む →

03

安全は待てない。方法はなお問える

窯を見守る人を守ることは、どんな設備リストも認めることではない。最低限を守り、窯を開く道も残すために、同じ取り決めの中で真剣に答える必要がある。

全文を読む →

04

却下もされず、道もない

決定によって道を握る関門も、決めないまま握る関門もある。決済、格付け、監査にも、問いかけの実際の入口が要る。

全文を読む →

05

買われるのは、一社だけではない

売り手が望んで売ることは重要だが、その道に頼る人へのすべての答えにはならない。競争の余地を残し、道を閉じることも一人で決着させない。

全文を読む →

06

資金が入るとき、どの決定が持ち去られるのか

見返りを分け、会社を管理し、人の行き先を動かすことは同じではない。資金は要求を伴ってよいが、善意や貪欲の名で全条項への答えにしてはならない。

全文を読む →

07

公開採決の後、誰がそれを変えられるのか

規制は、他人に説明を求めるだけでは済まない。公営の供給を審査するときも、供給者の所有者まで含めて独立性を確かめる必要がある。

全文を読む →

08

価格が海を渡った後、問いは誰に残るのか

安い品、国外の労働者、条約に基づく請求。距離で責任は消えず、どこまで扱えるかも、影響があるだけでは導けない。

全文を読む →

09

「市場がそうだから」を最後の言葉にしない

全体の結果を分析しながら、誰が説明し、誰が変えられるかも探す。このシリーズは市場の問いを具体的な立場へ返し、答えきれない強い問いも認める。

全文を読む →

『市場論』の前置き、七篇の本論、諸理論との対話をもとにした九篇。価格理論を述べたり、公営・私営、自由・計画という名で市場を分類したりはしない。

原論文と読む範囲

中国語の読者向け散文から訳した。前八篇の都市、工場、供給者、資金、国境を越える協定は設例で、実在の地域や企業を指さない。最終篇の思想文献と判例には出典と確認した範囲を示す。規範的判断と現行法は分け、分からない因果を事実として補わず、条約に基づく請求を裁定済みとは書かない。想定した仲裁権限は、現実の仲裁の一般則ではない。主な例、反問、一般的な答えのない箇所を残し、投資、法律、安全作業の助言は行わない。
