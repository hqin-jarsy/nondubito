笑话选 · 68

这笔账怎么算

捐钱、还钱、付诊费。钱到了手，未必就算明白了。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则
先从家里开始先写在账单上别让我站在这儿不能再受骗先付诊费不满意就赶我走

01

先从家里开始

“我刚给一个可怜的女人买了一袋面粉。”

“您又行善了！这回帮的是谁？”

“我妻子。”

出处与版本：先从家里开始

Mark Lemon 编：The Jest Book（1865） ↗

MCDXXIV（1424）：Charity Begins at Home

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 略去早晨新闻的寒暄，保留先受行善称赞、后揭示妻子身份的顺序。

02

先写在账单上

一位医生在旅馆病倒，店主送来一张很高的账单，请他先签认。

医生在底下写道：

“若我死了，这张账单算数；若我活下来，另行审查。”

出处与版本：先写在账单上

Mark Lemon 编：The Jest Book（1865） ↗

MCDXLVII（1447）：Conditional Agreement

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 这是旅馆向患病客人索取账单认可，不是医疗收费单；保留活下来才审账的条件。

03

别让我站在这儿

天寒地冻，募捐人拦住一位常年出钱的资助者，请他再帮一回。

那人不耐烦地说：“你爱写多少就写多少，只是别让我再站在冷风里！”

出处与版本：别让我站在这儿

Mark Lemon 编：The Jest Book（1865） ↗

MDIV（1504）：Charity and Inconvenience

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 只取寒天募捐轶事，省去开头对富人的一般化议论；不补实际捐款金额。

04

不能再受骗

年轻人向富朋友借了一百镑。朋友断定这钱收不回来了，结果他按数还清。

过了一阵，他又来借。

朋友说：“不借了。我可不能再受你骗。”

出处与版本：不能再受骗

Mark Lemon 编：The Jest Book（1865） ↗

MCCCXCVII（1397）：The Money-Borrower Deceived

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留富人预先认定不会还钱、结果钱被还清的前提，不混入借锅故事的生死借口。

本则固定链接

05

先付诊费

医生不收钱不开方，连给自己看病也一样。

所以每逢身体不适，他先从一个口袋里掏出一枚金币，放进另一个口袋。

出处与版本：先付诊费

Mark Lemon 编：The Jest Book（1865） ↗

MDCXLV（1645）：A Rule of Practice

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 省去 Bath 地名，将一基尼概写为金币；这是讽刺轶事，不是实际收费制度的说明。

06

不满意就赶我走

囚犯被带到监狱，狱官客气地说，只能拿出这些粗茶淡饭招待。

囚犯说：“您放心，我不会嫌弃。哪天我嫌弃了，您就把我赶出门去。”

出处与版本：不满意就赶我走

Mark Lemon 编：The Jest Book（1865） ↗

MDCXVI（1616）：An Unlikely Result

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原集系于 Thomas More 入塔，正文匿名化；只取招待与赶出门的问答，不据笑话集独立论断迫害史。
