一句也接得上

问年纪、看花园、听演说。话刚说出口，另一句就跟上了。

编选与中文译写：秦汉 · 约两三分钟

01

已经抖了半小时

两个决斗的人开过枪，谁也没打中。

一个见证人提议：“现在可以握手了吧。”

另一个说：“用不着。他们的手，已经抖了半小时了。”

出处与版本：已经抖了半小时

Mark Lemon 编：The Jest Book（1865） ↗

CCXXXVI（236）：Shaking Hands

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 英语 shake hands 与 hands shaking 的同词双关，中文以握手和手抖近写；不渲染决斗伤亡。

02

我先八岁

法官问老人多大年纪。老人说：“八岁又八十岁。”

“为什么不说八十又八岁？”

“因为我先到八岁，才到八十岁。”

出处与版本：我先八岁

Mark Lemon 编：The Jest Book（1865） ↗

CCLXXIV（274）：The Cart Before the Horse

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留法官询龄的场景；eight and fourscore 译为八岁又八十岁，不误作四十八岁。

03

这次说中了

一个人吹嘘：“我从来没说过真话。”

旁人说：“那你今天头一回说中了。”

出处与版本：这次说中了

Mark Lemon 编：The Jest Book（1865） ↗

CCCIII（303）：A Novelty

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留原文自指的矛盾答法，不为笑话另作逻辑修补。

04

每次都是这样

院长责备学生：“这草地不许学生踩。我每次往窗外看，都见你从上面走。”

学生说：“真巧，我每次从草地上走，也都见您往窗外看。”

出处与版本：每次都是这样

Mark Lemon 编：The Jest Book（1865） ↗

CCCXXXVI（336）：Ready Reply

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原场景是学院限制学生穿过草地；节取对答，不补受罚结果。

05

树为什么长得快

主人看着花园里的树，赞叹它们长得真快。

园丁说：“是啊，先生。请想一想，它们又没有别的事要做。”

出处与版本：树为什么长得快

Mark Lemon 编：The Jest Book（1865） ↗

CCCLIX（359）：A Good Reason

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留主人与园丁的短问答，不添加树种、肥料或植物学解释。

06

跟着鼓掌

有人参加聚会，听不大懂法语演说，便看旁边一位熟识的女士：她鼓掌，他也鼓掌。

结束后，一个孩子笑着告诉他：

“你刚才鼓掌最热烈的地方，是大家在夸你。”

出处与版本：跟着鼓掌

Mark Lemon 编：The Jest Book（1865） ↗

CCCLX（360）：Following a Leader

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原集归名 Franklin，正文匿名化；是听不大懂法语演说，非全不识法语。保留跟随熟识女士鼓掌及孩子提醒的转折。
