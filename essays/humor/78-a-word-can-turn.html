笑话选 · 78

话还能这样说

信没收到怎么办，讲道旧不旧，写得快的人又该不该夸。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则

01

没收到就写信

信写完，又添了一行：

“如果你没收到这封信，那一定是路上丢了。请写信告诉我。”

出处与版本：没收到就写信

Mark Lemon 编：The Jest Book（1865） ↗

DCL（650）：A Budget of Blunders，信末附言

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 仅取长信的附言，不收入政治背景、地域标签和前面的一连串矛盾；不是原书另有编号的短篇。

02

为谁操心

法官问律师：“你是替哪一方操心的？”

“我替原告操心。不过，雇我的是被告。”

出处与版本：为谁操心

Mark Lemon 编：The Jest Book（1865） ↗

DCCXI（711）：A Candid Counsel

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 concerned 兼指代理案件与感到忧虑，中文以操心／受雇展开；省去地域标签，不声称逐字复现双关。

03

也没那么旧

礼拜结束，牧师见管事笑得很得意，便问他什么事。

“他们说您今天又讲旧讲道。我替您驳回去了！”

“怎么驳的？”

“这怎么能叫旧呢？您上次讲这一篇，到现在还不到半年！”

出处与版本：也没那么旧

Mark Lemon 编：The Jest Book（1865） ↗

DCCXVI（716）：Save Us from Our Friends

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留管事向牧师复述自己辩护的话；距上次不到半年，不改成从未讲过的新讲道。

04

你知道吗

讲课的人正要开口，见台下一个人还在说笑，便问：

“你倒挺高兴。你知道我接下来要说什么吗？”

“不知道。您知道吗？”

出处与版本：你知道吗

Mark Lemon 编：The Jest Book（1865） ↗

DCCL（750）：Pert

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原文为即将开讲，非演讲中途被打断；省去 Macklin、Foote 专名，不另添讲者无话可说的结局。

05

夜里我不吃饭

学徒上工头一天，天还没亮，老板就来叫他：“起床！全家都坐下吃早饭了！”

男孩在床上翻了个身。

“谢谢，我没有夜里吃东西的习惯。”

出处与版本：夜里我不吃饭

Mark Lemon 编：The Jest Book（1865） ↗

DCCLXXVI（776）：Night and Morning

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 恢复新学徒第一天早晨的场景和翻身继续睡的动作；不泛写成长期每日催工。

06

一天和一星期

作者向朋友抱怨：“我一天写出来的开场诗，他竟然背了一个星期才背熟！”

“看来，他的记性确实不如你。”

出处与版本：一天和一星期

Mark Lemon 编：The Jest Book（1865） ↗

DCCXLIV（744）：An Effort of Memory

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留写作一天与背诵一周的对比及末句暗讽；不补具体被抄作品，也不作为剽窃事实的指控。
