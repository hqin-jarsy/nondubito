笑话选 · 66

听您这么一说

画家、演员和译者都等着听一句评语。有人还真接上了。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则

01

好的不用我夸

有人问画家：“怎么每次夸自己的画，您挑的都是那些不怎么样的？”

“好的那些，自己会说话。”

出处与版本：好的不用我夸

Mark Lemon 编：The Jest Book（1865） ↗

02

花了多少

演员去外地演出，照例住在各个熟人家里。

回来后，他大谈这趟旅行的开销，又问朋友：“你猜，我在那儿花了多少？”

“不知道。大概两个星期吧。”

出处与版本：花了多少

Mark Lemon 编：The Jest Book（1865） ↗

MCDXIX（1419）：An Expensive Trip

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 省去 Johnstone、Curran 的归名及地名；用花了保留 spent 在金钱与时间间的转折。

03

还有更可怕的

剧作家说：“对着一群挑剔的听众朗读自己的剧本，真没有比这更可怕的事。”

演员说：“我倒知道一件。非得坐在那里听。”

出处与版本：还有更可怕的

Mark Lemon 编：The Jest Book（1865） ↗

MCDXL（1440）：Theatrical Purgations

04

一样看不懂

一个人想向译者表示赞赏：

“最能让我相信您译得忠实的，就是原作里我看不懂的地方，在您的译本里也一样看不懂。”

出处与版本：一样看不懂

Mark Lemon 编：The Jest Book（1865） ↗

MCDLVII（1457）：A Close Translation

05

一点没打扰

作者滔滔不绝地向人讲自己的新作。过了一会儿，他说：“恐怕一直占用了您的注意力。”

“一点没有。我一直在想别的事。”

出处与版本：一点没打扰

Mark Lemon 编：The Jest Book（1865） ↗

MCDXC（1490）：No Intrusion

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原集答话者归名 Sheridan；将 attention 译为注意力，不改成时间，以保留答话逻辑。

06

各有各的本事

女演员问一位先生：“我和我的表，有什么不同？”

“您的表，让我们记住时间；您，让我们忘掉时间。”

出处与版本：各有各的本事

Mark Lemon 编：The Jest Book（1865） ↗

MCDLIII（1453）：Timely Flattery

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原文为 Mrs. Woffington 主动发问；不补赠表情节，保留记住与忘掉时间的对照。
