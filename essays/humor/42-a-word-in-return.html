您先说。说完了，我也有一句。

01

言归正传

两个人辩论，越说越激烈。其中一个气不过，端起一杯酒，泼在对方脸上。

对方掏出手帕，擦了擦脸。

“刚才这段算题外话。现在，咱们回到论证吧。”

出处与版本：言归正传

02

您听过吗

一个人讲了一桩离奇的故事，把听众听得直发愣。

他很得意：“您以前没听过吧？”

“没有。您以前听过吗？”

出处与版本：您听过吗

Mark Lemon 编：The Jest Book（1865） ↗

CML（950）：Pertinent Inquiry

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原文听众是听得发愣，不是毫无反应；保留反问，不提前点破讲述者在编故事。

照顾听众

一个人越说越气，话也越来越不像话。朋友提醒：“你知道自己在说蠢话吗？”

“知道。我总得让你听得懂。”

04

请继续

年轻律师站起来：“我这位不幸的当事人……”

停住了。他重新鼓了鼓劲：“我这位不幸的当事人……”

还是说不下去。

法官和气地说：“请继续。到目前为止，法庭完全同意。”

出处与版本：请继续

Mark Lemon 编：The Jest Book（1865） ↗

CMXCI（991）：Encouragement

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留年轻律师卡住、重复开头和法官插话的次序，不解释双关。

05

早安

几个学生碰见一个女人赶着驴。其中一个故意招呼：“早安，驴子的母亲！”

女人答道：“早安，我的孩子。”

出处与版本：早安

Mark Lemon 编：The Jest Book（1865） ↗

MX（1010）：Smart Reply

求点知识

一位议员站起身：“我起身，是为了求知。”

旁边有人说：“很高兴听您这么说。没有谁比您更需要了。”
