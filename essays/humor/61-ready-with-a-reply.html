笑话选 · 61

接得住话

诊室里，饭店里，法庭上，总有人接得出下一句。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则
这也能摸出来各有本领都长这么大了所以才乱区别就在这里您到哪儿都一样

01

这也能摸出来

庸医一边把脉，一边问：“你是不是觉得我是个骗子？”

病人说：“先生，您真能摸出别人心里想的事。”

出处与版本：这也能摸出来

Mark Lemon 编：The Jest Book（1865） ↗

CDXCIV（494）：At His Fingers' Ends

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 把脉与读心是人物的讽刺对白，不作诊疗能力说明。

02

各有本领

历史学家和医生都想讨一位女士的欢心。历史学家讲个没完，医生忍不住插话：

“她要听你的废话听病了，我来治。”

历史学家说：“她要被你的药治死了，我让她名垂千古。”

出处与版本：各有本领

Mark Lemon 编：The Jest Book（1865） ↗

DXIII（513）：The Rivals

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原集转述 Gibbon 等人的归名轶事，正文省名；保留医生与历史学家互相回敬，不把归名当作已经独立证实的会面。

03

都长这么大了

客人在饭店吃饭，让一个男孩拿盘子去添牛肉。等了好久，男孩才回来。

客人问：“你就是刚才拿走我盘子的那个孩子？”

“是，先生。”

“天哪，都长这么大了！”

出处与版本：都长这么大了

Mark Lemon 编：The Jest Book（1865） ↗

DXXI（521）：Time Works Wonders

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留等餐后认人的夸张，不将多年已经过去写成叙事事实。

04

所以才乱

律师盘问建筑师：“建筑师和砌房子的，差不多吧？”

建筑师解释，一个负责设计，一个负责施工。

律师又问：“那你说，乱成一团的巴别塔，是谁设计的？”

“没有建筑师，所以才乱。”

出处与版本：所以才乱

Mark Lemon 编：The Jest Book（1865） ↗

DXXXV（535）：A Satisfactory Reason

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 压缩职业高下争论，保留设计与施工的区分；巴别塔属于人物所用典故，不作建筑史断言。

05

区别就在这里

有人向一位女士介绍演员：“这位先生，没有看上去那么傻。”

演员说：“正是，夫人。这就是我和这位朋友最大的区别。”

出处与版本：区别就在这里

Mark Lemon 编：The Jest Book（1865） ↗

DXXXIX（539）：A Proper Retort

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 正文省去归名，保留介绍者的失礼与演员借原话回敬。

06

您到哪儿都一样

一位女演员来访，仆人一时找不到空椅子。

主人说：“您瞧，您到哪儿，哪儿就没有空座。”

出处与版本：您到哪儿都一样

Mark Lemon 编：The Jest Book（1865） ↗

DXC（590）：Johnson and Mrs. Siddons

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原集系于 Johnson 与 Mrs. Siddons；保留演员到访与无空座的双关，正文不另作人物考证。
