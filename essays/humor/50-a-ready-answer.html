还真答得上来

问一句，回一句。没想到的，往往是下一句。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则
两人的名字既然提到身份规定里的那一位别吵醒旁边的父亲的想法笔的问题

01

两人的名字

顾客嫌搬运工收费太高，问：“你叫什么名字？”

“跟我父亲一样。”

“你父亲叫什么？”

“跟我一样。”

“那你们两个人到底叫什么？”

“我们两个名字相同。”

说完，他走了。

出处与版本：两人的名字

Mark Lemon 编：The Jest Book（1865） ↗

MCXCIX（1199）：A Nameless Man

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留顾客追问姓名与搬运工三次绕开回答，不补造姓氏或投诉结果。

02

既然提到身份

一位作家到富人家做客，进门时，另一位客人停下来，让他先走。

主人对那位客人说：“您先请，不必客气。他只是个作家。”

作家走到前面：“既然特意提到我的身份，那我就不谦让了。”

出处与版本：既然提到身份

Mark Lemon 编：The Jest Book（1865） ↗

MCCIV（1204）：True Dignity

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留另一客人先让路、主人轻慢介绍、作家据此先行的顺序；不将匿名 P—— 扩写成可确证的人物。

03

规定里的那一位

将军住处前有一片草地，规定谁也不许横穿，只有他的奶牛例外。

一位女士想抄近路，被哨兵拦住了。

“你知道我是谁吗？”

“不知道，夫人。不过我知道，您不是将军的奶牛。”

出处与版本：规定里的那一位

Mark Lemon 编：The Jest Book（1865） ↗

MCCXXXI（1231）：A Poser

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留草地禁行、将军的奶牛除外这一明文例外；省去地名与女士的归名。

04

别吵醒旁边的

国王和一位大臣听布道，听着听着，都睡着了。大臣还打起了鼾。

牧师停下来，叫他：“劳驾，醒一醒。”

“您鼾声这么响，要把国王吵醒了。”

出处与版本：别吵醒旁边的

Mark Lemon 编：The Jest Book（1865） ↗

MCCXXXV（1235）：Sleeping at Church

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 所核原书写 Charles II，而底稿出处档案误记 James I；此处校正。正文省去国王、牧师与大臣姓名，仍作旧轶闻，不据此断言生平事实。

05

父亲的想法

军官说：“我要是有个笨儿子，就让他当牧师。”

牧师平静地答道：“这么说，您跟您父亲的想法不一样。”

出处与版本：父亲的想法

Mark Lemon 编：The Jest Book（1865） ↗

MCCLXXIV（1274）：Difference of Opinion

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 军官与牧师之间的回敬，保留由儿子转到父亲的暗指；不把职业与智力的联系当作事实。

06

笔的问题

一个人正写信，朋友站在旁边，指出这里拼错一个字，那里又有一句不通。

他把笔举起来：“我知道！可用这么一支笔，谁能写出通顺的句子？”

出处与版本：笔的问题

Mark Lemon 编：The Jest Book（1865） ↗

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原文为写信过程中被指出拼写语法错误；去掉地域标签，不以方言或族群身份作为笑点。
