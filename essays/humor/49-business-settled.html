笑话选 · 49

这事办妥了

房子分好了，邻居搬走了，生意也想好了。听着都不错。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则
已经分过了终于清静了还没花过钱绝无同行留着以后用只动我那一半

01

已经分过了

父亲留下遗嘱，房子要分给兄弟两人。哥哥却把弟弟赶了出去。

邻居看不下去，责问他怎么不照遗嘱办。

“我照办了呀。我分到里面，他分到外面。”

出处与版本：已经分过了

Mark Lemon 编：The Jest Book（1865） ↗

MCXCIV（1194）：A Will and Away

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原文遗嘱要求分房，未明确写等份；正文只写兄弟分有房子，保留里面与外面的曲解。

02

终于清静了

一个爱清静的人，偏偏住在铜匠和铁匠中间，天天敲得他头疼。他许下话：“你们谁肯搬走，我一定请客道谢。”

一天，两家一起上门报喜，都要搬了。他大喜，摆了一桌好酒菜。

酒过几巡，他问：“两位搬到哪儿去？”

“我搬他家，他搬我家。”

出处与版本：终于清静了

《笑府》 ↗

卷六〈好靜〉

据维基文库古文录文白话改写；不收篇后评语。 保留铜匠与铁匠交换住所；不收篇后的‘何不自迁’评语。

03

还没花过钱

布商挂出招牌：“低于成本，赔本出售！”

邻居看了看：“那倒不可能。这批货，他自己还一文钱都没付呢。”

出处与版本：还没花过钱

Mark Lemon 编：The Jest Book（1865） ↗

MCCVII（1207）：No Sacrifice

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留邻居用未付货款反驳低于成本的说法，作为笑话人物的诡辩，不作会计说明。

04

绝无同行

一个人想做独门生意，发现没人专卖皇帝戴的冠冕，便开了家店。等了好久，一个买主也没有。别人提醒：“皇帝在京城呢。”

他就带着货进京。半路借宿山里人家，夜间忽然有只老虎把爪子伸进门，哀哀地叫。他吓了一跳，壮着胆子举火一照，原来掌里扎了根竹刺。

拔掉刺，老虎欢欢喜喜走了。他更高兴：“我又添了一门没人会的本事！”

到了京城，挂出招牌：

“出售皇帝冠冕，兼拔老虎掌中刺。”

出处与版本：绝无同行

《笑府》 ↗

卷六〈獨行生意〉

据维基文库古文录文白话改写；不收篇后评语。 平天冠释作皇帝的冠冕；保留移店进京、夜宿时替虎拔刺、合写招牌的完整两段，不拆作不同故事。

05

留着以后用

一个快要破产的富人，向吝啬鬼请教：“我得怎么办，才能不穷下去？”

“照我这样过日子。”

“那种日子，等我真破产了再过也来得及。”

出处与版本：留着以后用

Mark Lemon 编：The Jest Book（1865） ↗

MCCLIX（1259）：A Last Resource

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 省去 Buckingham 与 Cutler 姓名；保留濒临破产者向吝啬人请教的反差。

06

只动我那一半

两个人合买一座谷仓，各占一半。一个把自己那边堆满粮食，另一个那边却一直空着。

前者忍不住劝：“你也该用起来呀，白花这笔钱，多可惜。”

“我自己那一半，总归随我怎么用吧？”

“当然。”

“那我想好了。我要把我这一半烧掉。”

出处与版本：只动我那一半

Mark Lemon 编：The Jest Book（1865） ↗

MCCLXII（1262）：A Pleasant Partner

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 两人共有同一座谷仓，不改成两座独立建筑；末句只是打算放火，原文未写已实施。
