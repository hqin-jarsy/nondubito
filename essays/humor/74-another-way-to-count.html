这也算一笔账

祖传的田、父亲的钱、赢来的官司，还有一顶该谁送的帽子。

编选与中文译写：秦汉 · 约两三分钟

这一辑的六则

01

我另外还有个差事

贵人问熟人：“我的田比你多，怎么倒不如你过得宽裕？”

“您忘了，我还有个差事。”

“什么差事？从没听说。”

“我兼着自己家的管家。”

出处与版本：我另外还有个差事

Mark Lemon 编：The Jest Book（1865） ↗

CCCI（301）：A Good Servant

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原为两位贵族的对话；place 指职务而非另一处房产，保留自己兼管家的回答。

02

田也还在

一个快把家产挥霍光的人，看见熟人穿着一件老式大衣，笑道：

“这还是你曾祖父的衣服吧？”

“是啊。可曾祖父的田，也还在我手里。”

出处与版本：田也还在

Mark Lemon 编：The Jest Book（1865） ↗

CCXCII（292）：A Deserved Retort

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留讥笑者已挥霍家产的前提；原文为相识者，不擅添邻居关系。

03

谁的父亲

儿子又向父亲要钱。父亲训他：“我像你这么大时，从没花过我父亲一个子儿！”

儿子说：“可您花了不少我父亲的钱。”

出处与版本：谁的父亲

Mark Lemon 编：The Jest Book（1865） ↗

CCCII（302）：Balancing Accounts

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 原集归名 Cibber 父子；补回儿子要钱及父亲比较同龄时花费的前提，省去金额和末尾借钱成功的旁白。

04

破产过两回

“我这辈子只破产过两回。”

“怎么回事？”

“头一回，官司打输了。第二回，打赢了。”

出处与版本：破产过两回

Mark Lemon 编：The Jest Book（1865） ↗

CCCLXII（362）：Twice Ruined

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留原文败诉与胜诉都破产的两分回答；不增加案件细节或实际诉讼费。

05

轻到十二盎司

面包师发明了一种新酵母。

做出的面包，轻极了——一磅只重十二盎司。

出处与版本：轻到十二盎司

Mark Lemon 编：The Jest Book（1865） ↗

CCCLXIX（369）：Light Bread

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 沿原文的一磅与十二盎司；此处一磅通常为十六盎司。保留轻盈与短斤少两的双关，不添加顾客少付钱的另一种笑话。

送顶帽子就算了

编辑在告别启事中写道：

“在我们短暂却辉煌的任职期间，若冒犯过哪位，请他送来一顶新帽子。这样，我们就可以把过去忘掉了。”

出处与版本：送顶帽子就算了

Mark Lemon 编：The Jest Book（1865） ↗

据 Project Gutenberg 所收英文笑话集译述；书中轶闻不等同于已经核实的历史事实。 保留编辑在告别启事中让被冒犯者送帽子的倒置；不补真诚道歉或无意伤害的声明。
