Non Dubito · AIと働く

AIと働く、自分を明け渡さずに

すでにAIを使っている。それでも、便利さに仕事や判断、人生の行き先まで決められたくはない。道具を使いこなすことから、自分の選択に答えられることへ進む八つのエッセイ。

8篇 · English / 简体中文 / 繁體中文 / Deutsch / Français / Español / 日本語 / 한국어

メールの下書き、よくできた回答、速くなった仕事。身近な場面から、何をAIに任せ、何を自分で引き受けるのかを考えます。AIを締め出すためではなく、その力を借りながら自分がいなくならない働き方を探すための連載です。

AIは作業を引き受けられます。けれども、「その作業は何のためなのか」を決める役まで、知らないうちに明け渡してはいけません。

下書き → 判断 → 選択 → 結果に答える

01 · 下書き

AIに書いてもらうことが、いちばんの危険なのではない

AIが間違った文章を書く。それは目につく危険です。もっと静かな危険は、文章があまりによくできていて、自分が何を言いたいのかを考える前に、完成した答えを受け入れてしまうことです。

本文を読む →

02 · 判断

プロンプトを書く力と、判断する力は違う

プロンプトをよくすれば、答えはよくなるかもしれません。でも、この場面でどの答えを行動の根拠にしてよいかまでは、指示の巧みさでは決まりません。

本文を読む →

03 · 効率と行き先

効率が、進む方向まで決め始めるとき

AIは、ただ私たちを速く進ませるだけではありません。いつのまにか指標が目的地に変わると、ある一方向しか道がないように見せることもあります。

本文を読む →

04 · 選んで引き受ける

AIは選択肢を出せる。でも、あなたの代わりには賭けられない

助言が決断になるのは、その選択の代償を引き受ける人がいるときです。その一歩を、指示で生成してもらうことはできません。

本文を読む →

05 · 記憶と責任

あなたを覚えていても、代わりに引き受けてはくれない

自分の過去をよく知るシステムは、もう一人の自分のように感じられます。記憶は協働を個人的なものにしますが、責任まで一緒に移してくれるわけではありません。

本文を読む →

06 · 書いたことを引き受ける

書くことの、最後の5％

「最後の5％」は、文字数の割合ではありません。滑らかな文章を、自分の言葉として引き受ける。その役目を指す比喩です。

本文を読む →

07 · 複数モデルで確かめる

三つのAIが同意しても、問いはまだ残る

複数のモデルは誤りを見つけ合い、探索を広げられます。ただ、その一致は証拠であって、人を離れたところにある最終審判の席ではありません。

本文を読む →

08 · ともに働くための約束

AIと本当に働くために、自分を明け渡さない

AIを拒むのでも、降伏するのでもない。できることは増やしながら、誰が決め、誰が結果に答えるのかを見失わない協働を組み立てます。

本文を読む →

ここで示すのは、AIとの協働をどう組み立てたいかという哲学的な提案です。現在の法律上の権利や、どの製品にも備わっている機能を説明するものではありません。目の前のやり取りで誰が結果を引き受けるのかを問い、将来のあらゆる人工システムについて結論を先取りしません。人とAIの担当割合を一律に決めることも、モデルの一致だけで証拠や判断が完成したとすることもありません。

八本の論文を要約したものではありません。すでに日々の仕事で起きていることを入口に、道具と、それを使って生きる人との間にどんな境目があるのかを考える、一般の読者に向けた道筋です。
