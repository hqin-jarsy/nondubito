国家の歩みと後戻り

権力への問いと、人が立つ場所

拘束の理由を問う人、差し戻された憲法、反対票、変化を求める街頭、制約を受ける王位、裁判所から排除された判事たち。六つの歴史をたどり、人が声を上げる資格を得、失い、取り戻そうとする過程を読む。これからも続いていく特集です。

六つの歴史随筆 · これからも続く特集 · English / 简体中文 / 繁體中文 / Deutsch / Français / Español / 日本語 / 한국어

実際の歴史を読む随筆です。架空の事例、現行法の案内、国の順位づけではありません。史料に記された出来事、裁判所の法的判断、筆者による構造の読み取りを区別し、対話や内心、複数人を合成した人物を創作していません。

国全体への判定からではなく、一人の置かれた状況から始めます。誰が問うことができ、誰が答えなければならないのか。答えが出れば、起きていることも変わるのか。歴史は問いを細かくし、ときに問いそのものを変えます。一つの理論を証明するためにあるのではありません。

選挙、審査、そして修復

インド · 1975–1979

閉じ込められたあとも、「なぜ」と問えるのか

非常事態の下でも裁判所は残り、後には選挙が政権を変えた。この二つを並べて初めて、問いを届ける道がどう閉じ、どう再び開かれたのかが見える。

南アフリカ · 1990–1997

可決された憲法を、なぜ書き直すのか

新しい多数派は、規則を書く資格を得るとともに、その規則が審査されることも受け入れた。しかし別の人々には、移行は、以前の道で過去の被害の責任を問えなくなることでもあった。

参加し続けられる条件

ドイツ · 1933年

あの投票の後にも、議会はあったのか

ヴェルスは反対する理由を述べ、九十四人が反対票を投じた。それでも法案は通った。失われたのは、一度の採決だけでなく、次の反対を有効にするための条件だった。

韓国 · 1987–1988

街頭で争い取った変化を、街頭の外へ残すには

朴鍾哲の死から大統領の直接選挙、そして新しい憲法裁判所へ。求めたのは、一度の勝利だけではない。毎回街へ戻らなくても、権力に答えを求められる可能性だった。

誰が同意し、誰が審査できるのか

イングランド · 1688–1701

王が一人で決められなくなっても、誰がなお入口の外にいたのか

新しい君主に王位が渡り、旧来の越権が一つひとつ文書にされた。議会は同意や問い直しの機会を増したが、その入口が全員へ同じように開いたわけではなかった。

パキスタン · 2007–2009

政府を調べる人が、先に裁判所から追い出されたら

最高裁長官が職を止められ、戻り、また排除された。裁判所の名は同じでも、そこに座れる人は変わる。弁護士、判決、街頭の圧力はどう帰還につながり、何はそれでも取り戻せなかったのか。

インドと南アフリカでは、選挙、審査、修復を。ドイツと韓国では、参加し続けられる条件を。イングランドとパキスタンでは、誰の同意が数えられ、誰が審査する立場に残れるのかを読み比べます。具体的な変化を対にして考えるのであって、六つの歴史を一つの発展段階の梯子に並べるのではありません。各篇は独立して読めます。
