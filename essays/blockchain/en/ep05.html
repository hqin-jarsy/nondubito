The Chisel–Construct Cycle · Blockchain 05 / 21

Ethereum

The “world computer” became a state machine priced by gas, leaving intent, governance, and the cost schedule to people.

Han Qin · 6 September 2026 · English rewrite

IN THIS ESSAY

  1. From money to a programmable state
  2. Gas makes computation legible
  3. A machine still has governors
  4. General interfaces multiply remainders

From money to a programmable state

Ethereum’s proposal was not simply to issue another currency. It offered a shared state machine on which programs could alter balances and data. Instead of asking the network to understand every application, the protocol supplied general execution. That abstraction opened an enormous design space: tokens, exchanges, organizations, games, and financial contracts could share one settlement layer.

Gas makes computation legible

Every operation consumes gas. This converts heterogeneous computation into a common cost and prevents programs from running forever. The measure is powerful because it is indifferent to purpose: useful code and harmful code pay by operations. Gas can price execution, but it does not decide whether an action was intended, fair, or socially worth its cost.

A machine still has governors

The protocol, client software, fee schedule, network upgrades, and early financing all required human decisions. “Code is law” can describe execution after code is accepted; it cannot explain who wrote the code, which client people run, or how a community responds to an exploit. The world computer always came with boards, developers, validators, and users around its edges.

General interfaces multiply remainders

A narrow payment system leaves some questions outside. A general programmable system invites far more of the world inside, and therefore produces more boundary cases: ownership without copyright, organizations without settled legal status, automated liquidation without situational mercy. Ethereum expanded what could be settled. It also expanded the number of places where settlement was mistaken for the whole relation.
