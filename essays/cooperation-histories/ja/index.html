ともに決めた、そのあとで

川、制裁、ワクチン、融資、そして現地への立入り。共同の決定がどうすれば実行できるものになり、誰の暮らしを変え、その後も問い直されていくのか。実際の歴史をたどります。

これからも続く特集 · 十四篇の歴史随筆 · English / 简体中文 / 繁體中文 / Deutsch / Français / Español / 日本語 / 한국어

実際の出来事を扱う歴史随筆です。事実、裁判上の判断、当事者の説明、筆者の解釈を分けて読み、各篇が示す時期の範囲で考えます。現行の法律や外交・医療実務を案内するものではありません。

川の水からでも、名簿に載った一つの名前からでも、漁網や疑いのある患者についての記録からでも読み始められます。先に理論を学ぶ必要はありません。七つの組から気になるものを選んでも、順に読んでもかまいません。何が行動を可能にし、その代償を誰が引き受け、誰がもう一度調べるよう求められるのか。具体的な出来事から考えます。

事故への対応、制裁、軍事行動、離脱後の取り決め、貿易条件、河川をめぐる仲裁、金融支援、保健や環境の事業では、機関に認められた権限も、利用できる救済の道も同じではありません。後の改善は、それ以前の決定をすべて正当化しません。残された問題があるからといって、実際になされた仕事まで消えるわけでもありません。十四篇は成功と失敗の順位表でも、順に上がる段階でもなく、違いを残して並べて読むためのものです。

史料と読み方について

この連載は実際の歴史を扱います。場面を創作せず、現行法の実務案内も行いません。史料が伝える事実、当時の法的判断、機関自身による評価、筆者の解釈を区別し、記録にない内心や対話、複数の被害者を組み合わせた人物は作りません。英語版は英語の読者に向けて独立に書かれ、簡体字・繁体字の中国語版はいずれも全文を収録しています。この日本語版は現在の中国語の随筆を底本に、読者に向けて独立に書き直したものです。最初の調査報告は題材選びの助けとしたもので、リンク先で確かめられる元の記録に代わるものではありません。ここに登場する異なる組織が、どれも理論でいう「共通の強制的な上位者を持たない協力」に当てはまると決めつけることもしません。哲学的な背景をさらに読みたい方には、英語・中国語の前置論文があります。読むかどうかは自由です。歴史に理論を証明させるのではなく、理論が差し出す問いを歴史に照らして確かめます。
