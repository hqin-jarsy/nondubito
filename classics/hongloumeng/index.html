八十回回目

共八十回，按每五回分组。

第1至5回

  1. 01第一回 甄士隐梦幻识通灵 贾雨村风尘怀闺秀
  2. 02第二回 贾夫人仙逝扬州城 冷子兴演说荣国府
  3. 03第三回 金陵城起复贾雨村 荣国府收养林黛玉
  4. 04第四回 薄命女偏逢薄命郎 葫芦僧乱判葫芦案
  5. 05第五回 游幻境指迷十二钗 饮仙醪曲演红楼梦

第6至10回

  1. 06第六回 贾宝玉初试云雨情 刘姥姥一进荣国府
  2. 07第七回 送宫花贾琏戏熙凤 宴宁府宝玉会秦钟
  3. 08第八回 比通灵金莺微露意 探宝钗黛玉半含酸
  4. 09第九回 恋风流情友入家塾 起嫌疑顽童闹学堂
  5. 10第十回 金寡妇贪利权受辱 张太医论病细穷源

第11至15回

  1. 11第十一回 庆寿辰宁府排家宴 见熙凤贾瑞起淫心
  2. 12第十二回 王熙凤毒设相思局 贾天祥正照风月鉴
  3. 13第十三回 秦可卿死封龙禁尉 王熙凤协理宁国府
  4. 14第十四回 林如海捐馆扬州城 贾宝玉路谒北静王
  5. 15第十五回 王凤姐弄权铁槛寺 秦鲸卿得趣馒头庵

第16至20回

  1. 16第十六回 贾元春才选凤藻宫 秦鲸卿夭逝黄泉路
  2. 17第十七回 大观园试才题对额 荣国府归省庆元宵
  3. 18第十八回 皇恩重元妃省父母 天伦乐宝玉呈才藻
  4. 19第十九回 情切切良宵花解语 意绵绵静日玉生香
  5. 20第二十回 王熙凤正言弹妒意 林黛玉俏语谑娇音

第21至25回

  1. 21第二十一回 贤袭人娇嗔箴宝玉 俏平儿软语救贾琏
  2. 22第二十二回 听曲文宝玉悟禅机 制灯迷贾政悲谶语
  3. 23第二十三回 西厢记妙词通戏语 牡丹亭艳曲警芳心
  4. 24第二十四回 醉金刚轻财尚义侠 痴女儿遗帕惹相思
  5. 25第二十五回 魇魔法姊弟逢五鬼 红楼梦通灵遇双真

第26至30回

  1. 26第二十六回 蜂腰桥设言传心事 潇湘馆春困发幽情
  2. 27第二十七回 滴翠亭杨妃戏彩蝶 埋香冢飞燕泣残红
  3. 28第二十八回 蒋玉菡情赠茜香罗 薛宝钗羞笼红麝串
  4. 29第二十九回 享福人福深还祷福 痴情女情重愈斟情
  5. 30第三十回 宝钗借扇机带双敲 龄官划蔷痴及局外

第31至35回

  1. 31第三十一回 撕扇子作千金一笑 因麒麟伏白首双星
  2. 32第三十二回 诉肺腑心迷活宝玉 含耻辱情烈死金钏
  3. 33第三十三回 手足耽耽小动唇舌 不肖种种大遭笞挞
  4. 34第三十四回 情中情因情感妹妹 错里错以错劝哥哥
  5. 35第三十五回 白玉钏亲尝莲叶羹 黄金莺巧结梅花络

第36至40回

  1. 36第三十六回 绣鸳鸯梦兆绛芸轩 识分定情悟梨香院
  2. 37第三十七回 秋爽斋偶结海棠社 蘅芜苑夜拟菊花题
  3. 38第三十八回 林潇湘魁夺菊花诗 薛蘅芜讽和螃蟹咏
  4. 39第三十九回 村姥姥是信口开合 情哥哥偏寻根究底
  5. 40第四十回 史太君两宴大观园 金鸳鸯三宣牙牌令

第41至45回

  1. 41第四十一回 栊翠庵茶品梅花雪 怡红院劫遇母蝗虫
  2. 42第四十二回 蘅芜君兰言解疑癖 潇湘子雅谑补余香
  3. 43第四十三回 闲取乐偶攒金庆寿 不了情暂撮土为香
  4. 44第四十四回 变生不测凤姐泼醋 喜出望外平儿理妆
  5. 45第四十五回 金兰契互剖金兰语 风雨夕闷制风雨词

第46至50回

  1. 46第四十六回 尴尬人难免尴尬事 鸳鸯女誓绝鸳鸯偶
  2. 47第四十七回 呆霸王调情遭苦打 冷郎君惧祸走他乡
  3. 48第四十八回 滥情人情误思游艺 慕雅女雅集苦吟诗
  4. 49第四十九回 琉璃世界白雪红梅 脂粉香娃割腥啖膻
  5. 50第五十回 芦雪庵争联即景诗 暖香坞雅制春灯谜

第51至55回

  1. 51第五十一回 薛小妹新编怀古诗 胡庸医乱用虎狼药
  2. 52第五十二回 俏平儿情掩虾须镯 勇晴雯病补雀金裘
  3. 53第五十三回 宁国府除夕祭宗祠 荣国府元宵开夜宴
  4. 54第五十四回 史太君破陈腐旧套 王熙凤效戏彩斑衣
  5. 55第五十五回 辱亲女愚妾争闲气 欺幼主刁奴蓄险心

第56至60回

  1. 56第五十六回 敏探春兴利除宿弊 识宝钗小惠全大体
  2. 57第五十七回 慧紫鹃情辞试莽玉 慈姨妈爱语慰痴颦
  3. 58第五十八回 杏子阴假凤泣虚凰 茜纱窗真情揆痴理
  4. 59第五十九回 柳叶渚边嗔莺咤燕 绛云轩里召将飞符
  5. 60第六十回 茉莉粉替去蔷薇硝 玫瑰露引来茯苓霜

第61至65回

  1. 61第六十一回 投鼠忌器宝玉瞒赃 判冤决狱平儿行权
  2. 62第六十二回 憨湘云醉眠芍药裀 呆香菱情解石榴裙
  3. 63第六十三回 寿怡红群芳开夜宴 死金丹独艳理亲丧
  4. 64第六十四回 幽淑女悲题五美吟 浪荡子情遗九龙珮
  5. 65第六十五回 贾二舍偷娶尤二姨 尤三姐思嫁柳二郎

第66至70回

  1. 66第六十六回 情小妹耻情归地府 冷二郎一冷入空门
  2. 67第六十七回 见土仪颦卿思故里 闻秘事凤姐讯家童
  3. 68第六十八回 苦尤娘赚入大观园 酸凤姐大闹宁国府
  4. 69第六十九回 弄小巧用借剑杀人 觉大限吞生金自逝
  5. 70第七十回 林黛玉重建桃花社 史湘云偶填柳絮词

第71至75回

  1. 71第七十一回 嫌隙人有心生嫌隙 鸳鸯女无意遇鸳鸯
  2. 72第七十二回 王熙凤恃强羞说病 来旺妇倚势霸成亲
  3. 73第七十三回 痴丫头误拾绣春囊 懦小姐不问累金凤
  4. 74第七十四回 惑奸谗抄检大观园 矢孤介杜绝宁国府
  5. 75第七十五回 开夜宴异兆发悲音 赏中秋新词得佳谶

第76至80回

  1. 76第七十六回 凸碧堂品笛感凄清 凹晶馆联诗悲寂寞
  2. 77第七十七回 俏丫鬟抱屈夭风流 美优伶斩情归水月
  3. 78第七十八回 老学士闲征姽婳词 痴公子杜撰芙蓉诔
