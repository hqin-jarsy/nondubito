八十回回目

共八十回，按每五回分組。

第1至5回

  1. 01第一回 甄士隱夢幻識通靈 賈雨村風塵懷閨秀
  2. 02第二回 賈夫人仙逝揚州城 冷子興演說榮國府
  3. 03第三回 金陵城起復賈雨村 榮國府收養林黛玉
  4. 04第四回 薄命女偏逢薄命郎 葫蘆僧亂判葫蘆案
  5. 05第五回 游幻境指迷十二釵 飲仙醪曲演紅樓夢

第6至10回

  1. 06第六回 賈寶玉初試雲雨情 劉姥姥一進榮國府
  2. 07第七回 送宮花賈璉戲熙鳳 宴寧府寶玉會秦鐘
  3. 08第八回 比通靈金鶯微露意 探寶釵黛玉半含酸
  4. 09第九回 戀風流情友入家塾 起嫌疑頑童鬧學堂
  5. 10第十回 金寡婦貪利權受辱 張太醫論病細窮源

第11至15回

  1. 11第十一回 慶壽辰寧府排家宴 見熙鳳賈瑞起淫心
  2. 12第十二回 王熙鳳毒設相思局 賈天祥正照風月鑒
  3. 13第十三回 秦可卿死封龍禁尉 王熙鳳協理寧國府
  4. 14第十四回 林如海捐館揚州城 賈寶玉路謁北靜王
  5. 15第十五回 王鳳姐弄權鐵檻寺 秦鯨卿得趣饅頭庵

第16至20回

  1. 16第十六回 賈元春才選鳳藻宮 秦鯨卿夭逝黃泉路
  2. 17第十七回 大觀園試才題對額 榮國府歸省慶元宵
  3. 18第十八回 皇恩重元妃省父母 天倫樂寶玉呈才藻
  4. 19第十九回 情切切良宵花解語 意綿綿靜日玉生香
  5. 20第二十回 王熙鳳正言彈妒意 林黛玉俏語謔嬌音

第21至25回

  1. 21第二十一回 賢襲人嬌嗔箴寶玉 俏平兒軟語救賈璉
  2. 22第二十二回 聽曲文寶玉悟禪機 制燈迷賈政悲讖語
  3. 23第二十三回 西廂記妙詞通戲語 牡丹亭艷曲警芳心
  4. 24第二十四回 醉金剛輕財尚義俠 痴女兒遺帕惹相思
  5. 25第二十五回 魘魔法姊弟逢五鬼 紅樓夢通靈遇雙真

第26至30回

  1. 26第二十六回 蜂腰橋設言傳心事 瀟湘館春困發幽情
  2. 27第二十七回 滴翠亭楊妃戲彩蝶 埋香冢飛燕泣殘紅
  3. 28第二十八回 蔣玉菡情贈茜香羅 薛寶釵羞籠紅麝串
  4. 29第二十九回 享福人福深還禱福 痴情女情重愈斟情
  5. 30第三十回 寶釵借扇機帶雙敲 齡官划薔痴及局外

第31至35回

  1. 31第三十一回 撕扇子作千金一笑 因麒麟伏白首雙星
  2. 32第三十二回 訴肺腑心迷活寶玉 含恥辱情烈死金釧
  3. 33第三十三回 手足耽耽小動唇舌 不肖種種大遭笞撻
  4. 34第三十四回 情中情因情感妹妹 錯裡錯以錯勸哥哥
  5. 35第三十五回 白玉釧親嘗蓮葉羹 黃金鶯巧結梅花絡

第36至40回

  1. 36第三十六回 繡鴛鴦夢兆絳芸軒 識分定情悟梨香院
  2. 37第三十七回 秋爽齋偶結海棠社 蘅蕪苑夜擬菊花題
  3. 38第三十八回 林瀟湘魁奪菊花詩 薛蘅蕪諷和螃蟹詠
  4. 39第三十九回 村姥姥是信口開合 情哥哥偏尋根究底
  5. 40第四十回 史太君兩宴大觀園 金鴛鴦三宣牙牌令

第41至45回

  1. 41第四十一回 櫳翠庵茶品梅花雪 怡紅院劫遇母蝗蟲
  2. 42第四十二回 蘅蕪君蘭言解疑癖 瀟湘子雅謔補餘香
  3. 43第四十三回 閒取樂偶攢金慶壽 不了情暫撮土為香
  4. 44第四十四回 變生不測鳳姐潑醋 喜出望外平兒理妝
  5. 45第四十五回 金蘭契互剖金蘭語 風雨夕悶制風雨詞

第46至50回

  1. 46第四十六回 尷尬人難免尷尬事 鴛鴦女誓絕鴛鴦偶
  2. 47第四十七回 呆霸王調情遭苦打 冷郎君懼禍走他鄉
  3. 48第四十八回 濫情人情誤思遊藝 慕雅女雅集苦吟詩
  4. 49第四十九回 琉璃世界白雪紅梅 脂粉香娃割腥啖羶
  5. 50第五十回 蘆雪庵爭聯即景詩 暖香塢雅制春燈謎

第51至55回

  1. 51第五十一回 薛小妹新編懷古詩 胡庸醫亂用虎狼藥
  2. 52第五十二回 俏平兒情掩蝦鬚鐲 勇晴雯病補雀金裘
  3. 53第五十三回 寧國府除夕祭宗祠 榮國府元宵開夜宴
  4. 54第五十四回 史太君破陳腐舊套 王熙鳳效戲彩斑衣
  5. 55第五十五回 辱親女愚妾爭閒氣 欺幼主刁奴蓄險心

第56至60回

  1. 56第五十六回 敏探春興利除宿弊 識寶釵小惠全大體
  2. 57第五十七回 慧紫鵑情辭試莽玉 慈姨媽愛語慰痴顰
  3. 58第五十八回 杏子陰假鳳泣虛凰 茜紗窗真情揆痴理
  4. 59第五十九回 柳葉渚邊嗔鶯吒燕 絳雲軒裡召將飛符
  5. 60第六十回 茉莉粉替去薔薇硝 玫瑰露引來茯苓霜

第61至65回

  1. 61第六十一回 投鼠忌器寶玉瞞贓 判冤決獄平兒行權
  2. 62第六十二回 憨湘雲醉眠芍藥裀 呆香菱情解石榴裙
  3. 63第六十三回 壽怡紅群芳開夜宴 死金丹獨艷理親喪
  4. 64第六十四回 幽淑女悲題五美吟 浪蕩子情遺九龍珮
  5. 65第六十五回 賈二舍偷娶尤二姨 尤三姐思嫁柳二郎

第66至70回

  1. 66第六十六回 情小妹恥情歸地府 冷二郎一冷入空門
  2. 67第六十七回 見土儀顰卿思故里 聞秘事鳳姐訊家童
  3. 68第六十八回 苦尤娘賺入大觀園 酸鳳姐大鬧寧國府
  4. 69第六十九回 弄小巧用借劍殺人 覺大限吞生金自逝
  5. 70第七十回 林黛玉重建桃花社 史湘雲偶填柳絮詞

第71至75回

  1. 71第七十一回 嫌隙人有心生嫌隙 鴛鴦女無意遇鴛鴦
  2. 72第七十二回 王熙鳳恃強羞說病 來旺婦倚勢霸成親
  3. 73第七十三回 痴丫頭誤拾繡春囊 懦小姐不問累金鳳
  4. 74第七十四回 惑奸讒抄檢大觀園 矢孤介杜絕寧國府
  5. 75第七十五回 開夜宴異兆發悲音 賞中秋新詞得佳讖

第76至80回

  1. 76第七十六回 凸碧堂品笛感淒清 凹晶館聯詩悲寂寞
  2. 77第七十七回 俏丫鬟抱屈夭風流 美優伶斬情歸水月
  3. 78第七十八回 老學士閒徵姽嫿詞 痴公子杜撰芙蓉誄
  4. 79第七十九回 薛文龍悔娶河東獅 賈迎春誤嫁中山狼
  5. 80第八十回 美香菱屈受貪夫棒 王道士胡謅妒婦方
